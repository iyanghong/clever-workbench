# 02: 系统菜单与按需批量操作

What to build: 在新台账布局中收纳系统管理动作，按真实选择状态展示批量操作，让界面简洁且复制、导出和录入仍可直接完成。

Blocked by: 01 台账浏览与宽详情

Status: ready-for-human

Completion: verified

规格：[共用框架与台账布局优化](../spec.md)。原型依据同规格中的方案 B。

- [x] 系统信息和导出资料位于当前系统的更多菜单，系统收藏继续可用。
- [x] 新增系统进入系统切换器；无系统时仍有明确新建入口，切换／新建／导出等待必要保存并使用正确背景。
- [x] 更多与系统选择支持键盘进入、Esc 关闭、焦点返回和清楚的可访问名称；控件排除窗口拖拽区域。
- [x] 未选择时保留选择与计数入口，隐藏无效批量动作；选择后显示数量、复制、包含账号及取消选择。
- [x] 筛选或对象变化后选择边界有效，摘要与完整清单之间保持真实复制行为；秘密解锁和保存失败保护不退化。
- [x] 在 Electron 中验证系统信息、导出、新建系统、批量复制、取消选择及菜单键盘行为，并更新受影响的既有回归操作。
