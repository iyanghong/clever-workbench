# 共用框架与台账布局优化

Status: ready-for-human

Completion: verified — 方案 B 已在集成分支实现，完成开发构建验收和双轴审查；平台及安装版边界见[实施记录](implementation.md)。

确认日期：2026-10-21。设计基线：v0.1.7。用户已选择原型 **B：紧凑工具栏**，并确认本文的 Electron 验收边界。

## Problem Statement

台账的全局命令栏、系统动作、分类、筛选和批量工具连续占据多个层次。打开对象后，完整表格仍占用较大宽度，单条资料的正文、账号和编辑区域受到挤压。快速新建的九项入口缺少分组，使界面的主次不够清楚。

用户希望优先改善布局与视觉，采用“列表紧凑、详情舒展”的密度，沿用现有 macOS 风格，保留日常查找、录入、复制、保存与恢复能力。

## Solution

采用已选原型 B 的信息结构：稳定的全局搜索与新建入口；紧凑的当前系统工具栏；横向资料分类；按当前浏览状态分配空间的列表与详情。

未打开对象时保留完整表格，便于多列比较。打开对象后，宽窗口呈现带搜索和筛选的左侧摘要列表，以及更宽的右侧详情。窄窗口只显示详情，清晰的“返回清单”恢复原有分类、搜索、筛选和列表位置。

系统信息和导出资料放入当前系统的“更多”菜单，新增系统放入系统切换器。批量动作仅在选择记录后出现。用户名、地址、秘密等高频复制入口仍在对象附近。

快速新建在同一弹窗直接展示“工作记录”和“台账资料”两组，完整保留九项动作。所有功能继续使用真实业务接口和原有安全边界。

## User Stories

1. 作为工作台用户，我希望搜索和新建位于稳定位置，以便在不同页面快速找到全局入口。
2. 作为台账用户，我希望当前系统清晰可见，以便确认自己正在查看哪一套资料。
3. 作为台账用户，我希望分类占用较少的垂直空间，以便首屏展示更多真实资料。
4. 作为台账用户，我希望未选择对象时看到完整表格，以便横向比较名称、地址、归属和说明。
5. 作为台账用户，我希望打开对象后看到摘要列表与宽详情，以便连续浏览多条记录。
6. 作为台账用户，我希望摘要保留名称、环境或标签、关键地址和必要的归属，以便辨认名称相近的对象。
7. 作为台账用户，我希望当前选中对象有清楚的结构标记，以便在深浅主题下都能确认选择。
8. 作为台账用户，我希望搜索和筛选紧邻摘要列表，以便理解它们改变的是资料集合。
9. 作为台账用户，我希望环境、标签及运维专用筛选继续有效，以便沿用熟悉的查找方式。
10. 作为台账用户，我希望宽窗口返回完整清单时保留查找条件和位置，以便继续比较记录。
11. 作为窄窗口用户，我希望详情单栏显示且能返回清单，以便不被过宽表格挤压。
12. 作为台账用户，我希望长地址、标题和备注可以换行或滚动，以便主要操作仍然可达。
13. 作为台账用户，我希望地址和资料复制仍就近可用，以便快速把信息用于工作。
14. 作为账号用户，我希望用户名和密码、Token、私钥的复制继续直接可达，以便不因布局调整增加重复操作。
15. 作为账号用户，我希望完整清单保留已有的秘密显隐和批量能力，以便原有使用方式继续有效。
16. 作为台账用户，我希望未勾选记录时不看到一排不可用的批量动作，以便界面保持清晰。
17. 作为台账用户，我希望勾选后看到数量、全选、复制及相关选项，并能取消选择，以便批量处理过程可理解。
18. 作为编辑者，我希望切换对象、返回清单和打开其他动作之前等待保存，以便输入不会丢失。
19. 作为编辑者，我希望保存失败时保留输入和重试方式，以便复制或切页不会悄悄使用旧资料。
20. 作为台账用户，我希望系统信息和导出仍明确属于当前系统，以便在简化顶部后不误操作其他系统。
21. 作为台账用户，我希望从系统切换器新建系统，并在没有系统时也能开始录入，以便空状态有明确下一步。
22. 作为录入用户，我希望当前分类新增和粘贴表格入口清楚可见，以便保留快速录入效率。
23. 作为工作记录用户，我希望新任务、新文档位于新建弹窗前方，以便快速开始记录。
24. 作为台账用户，我希望另外七项新建入口在同一弹窗内直接选择，以便不增加额外导航层级。
25. 作为录入用户，我希望新建沿用已确认的系统、环境和资源背景，以便减少重复选择。
26. 作为键盘用户，我希望菜单、弹窗可以用键盘操作、Esc 关闭并返回焦点，以便无需依赖鼠标。
27. 作为外观偏好用户，我希望深浅主题、跟随系统、高对比度、减少透明度和减少动态效果继续有效，以便长时间使用舒适可读。
28. 作为桌面用户，我希望工具栏和弹窗按钮能响应真实鼠标点击，以便窗口拖拽区域不会吞掉操作。
29. 作为现有用户，我希望首页、任务、文档、设置和更新弹窗继续正常工作，以便共用样式调整不造成其他页面退化。
30. 作为资料所有者，我希望布局优化不改变资料模型、秘密保护和备份恢复方式，以便升级后资料仍可信。

## Implementation Decisions

- 沿用现有 Electron、React、类型化 DesktopAPI、SQLite 分层。本轮不新增持久化字段、IPC、资料格式或领域含义。
- 正式代码以 v0.1.7 为基础，原型 B 仅作为信息结构和空间分配的依据；不引入演示数据、模拟接口、原型底栏或方案切换参数。
- 应用壳保持左侧导航、顶部全局搜索及新建。通过语义颜色、对齐、标题层级和控件密度统一视觉；不更改模块路由或导航业务含义。
- 台账在完整表格与摘要列表之间根据是否打开详情切换。摘要按真实对象类型展示可识别信息，不能只截取通用名称；账号保留所属入口或资源信息。
- 摘要列表与完整表格共享当前系统、分类、搜索、环境和标签状态。保留既有列表位置记忆，避免摘要滚动覆盖完整表格的返回位置。
- 搜索词变化可以保留当前详情；环境、标签、运维范围变化沿用既有行为，先保存再关闭详情，避免详情属于旧范围却使用新范围复制。布局调整不放宽主进程的范围校验。
- 宽窗口中筛选位于列表侧，详情占据剩余空间。根据内容区域可用宽度切换单栏；不以完整表格的最小宽度挤压详情。窄窗口返回清单后恢复筛选入口。
- 运维类型与状态筛选、空状态、加载状态、当前分类新增、表格粘贴以及现有文档导航保持实际业务行为。文档仍进入现有文档工作区，不新建一套台账文档编辑器。
- 详情复用现有读取、编辑组件及保存协调。切换、返回、复制、导出和新建继续等待相关保存，失败时保持输入与位置。
- 单条资料、字段、用户名和秘密复制复用现有能力；秘密的解锁、锁定清理和剪贴板保护保持一致。完整账号清单保留已有显隐、范围和批量行为。
- 系统切换器增加明确的新增系统动作；当前系统的更多菜单包含系统信息和导出。系统收藏入口保留，菜单与原生拖拽区域隔离。
- 批量工具按真实选择状态展开。未选择时保留清楚的选择入口和数量；选择后完整呈现既有能力及取消选择。筛选或对象变化沿用并核验原有有效选择边界。
- 新建弹窗只重组显示：工作记录为新任务、新文档；台账资料为新系统、新访问入口、新账号、新服务器、新资源、新环境、新服务。沿用动作注册、排序、创建背景、表单、错误提示和执行逻辑。
- 新菜单具备可访问名称、展开状态、键盘进入、Esc 关闭和焦点返回；弹窗继续复用共享对话框，不引入另一套焦点或关闭机制。
- 不统一放大或缩小所有内容。列表采用紧凑密度，详情保留阅读留白；正文和辅助信息保持可读对比度。布局规则限定到本次相关区域，减少对其他模块的影响。
- 不新增依赖或架构抽象。只有具体重复布局需要时提取小型展示组件，业务状态与真实保存链路继续归既有模块负责。

## Testing Decisions

用户于 2026-10-21 明确确认：**“符合，沿用这些验收边界”**。

- 主要验收边界为现有 Playwright Electron 桌面入口，使用隔离资料目录和多条虚构资料，以可观察行为和实际页面几何尺寸验收；不通过断言 CSS 类名或组件内部状态替代用户结果。
- 复用现有台账工作区、台账复制、账号清单、统一新建、主题与对话框用例的夹具及交互方式。新增回归覆盖打开对象后摘要与宽详情共存、窄窗口单栏、返回后筛选和位置保留、长内容及空结果。
- 检查真实单条／批量复制、账号秘密复制、取消解锁、锁定清理，以及编辑未保存／保存失败时的导航和复制行为，不能用原型模拟提示作为通过证据。
- 检查系统切换、新建系统、当前系统信息和导出；验证菜单、弹窗的键盘、Esc、焦点返回及实际背景传递。
- 检查分组新建的两组九项入口，至少沿用真实任务和台账新建路径验证创建背景、保存协调及关闭恢复。
- 在正常与窄窗口、浅色与深色下检查列表、详情、菜单和新建；沿用现有外观测试覆盖跟随系统、高对比、减少透明度和减少动态效果。
- 对共用框架改动回归首页、任务、文档、设置及更新弹窗。涉及工具栏或弹窗拖拽区域的交互须补充真实原生鼠标验证。
- 运行类型检查、生产构建、相关桌面回归，并在集成结束运行完整测试集。检查失败保留实际结论，不能把浏览器原型观察写成安装版或原生验收通过。
- 本轮不触及数据库、加密或更新安装逻辑，不为这些未改动内部实现新增重复单元测试。若实施发现必须改变业务边界，先明确新增范围。

## Out of Scope

- 首页、任务和文档页面的独立布局改版；这些页面仅接受必要的共用框架调整和回归。
- 最初体验评审中的时间保存一致性、搜索语义、跨模块工作位置记忆、后台通知等独立功能。
- 新领域对象、云同步、多人协作、新平台、资料迁移及凭据格式调整。
- 改变更新功能、发布脚本、Release 来源或安装流程。
- 将演示原型直接合入产品、推送分支、发布 Release 或替换本机安装版。
