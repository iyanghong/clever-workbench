# 任务页项目选择无法点击

Status: ready-for-agent

2026-10-19：用户截图指出任务页顶部“全部项目”无法切换。修复现有项目筛选，沿用既有实现授权；不调整资料模型或项目归属规则。

## 验收

- 项目选择控件接收原生鼠标输入，不落入窗口拖动区域；工具栏空白仍可拖动窗口。
- 可以在具体项目、未分类和全部项目之间切换，任务列表同步过滤。
- 已有任务快录、详情保存和其他工具栏操作继续可用。
- 修复提交并更新安装包，使用独立虚构资料验证。

## 诊断记录

普通 DOM 选项切换测试通过，说明项目和任务筛选逻辑正常。将检查收窄到实际 Electron 的原生鼠标命中区域后，`npx playwright test tests/e2e/project-filter.spec.ts` 在旧样式中稳定失败（约 1.4 秒）：预期控件不属于窗口拖动区域，实际为拖动区域。该检查与项目内容无关，最小失败边界是工具栏中的 select。

候选原因按顺序为：①工具栏拖动区域截获鼠标，单独排除 select 后命中检查与鼠标操作应恢复；②控件／菜单焦点异常，修正拖动区域后仍会无法选择；③额外覆盖层截获鼠标，排除拖动区域后仍会命中其他元素。只改变第一项验证。

现有公共样式给工具栏声明 drag，并将 button、input、label 排除，遗漏 select。根据 [Electron 原生拖动区域说明](https://www.electronjs.org/docs/latest/tutorial/custom-window-interactions)，拖动区域不接收指针事件，需要显式 no-drag。实际回归同时检查该平台边界和项目筛选结果；DOM selectOption 本身会绕过原生命中，不能单独证明鼠标可用。
