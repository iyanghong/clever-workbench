# 访问入口与服务器扩展审查

固定起点：`1a245a9fa2a44b7371d483893d3329667ab18299`。首次审查终点：`b8d8089c7a4f722e54d4ce8f4a24b5bac6f3991d`。Standards 与 Spec 使用独立并行审查，随后分别复核工作区修复。

## Standards

未发现违反 AGENTS.md、领域术语或 ADR 0005 的硬性问题。两项 P3 判断项已修复并复核：备份预检重复解析账号归属，现保留一次带字段校验的返回值；秘密复制曾按账号名称重新匹配，现直接使用台账复制产生的账号 ID 映射，事务与公开 API 保持不变。

## Spec

发现 P1：更改访问入口或服务器环境后马上编辑账号，环境保存使账号组件重挂载，静默丢失尚未自动保存的输入。真实 Electron 回归先复现用户名仍为旧值，再验证稳定组件身份及筛选保留当前记录的修复。

复核补充两条路径：P1，服务器专页改变资源类型会使记录退出列表；P2，手动筛选完成保存后读取旧闭包，撤销用户筛选。服务器专页现固定类型，环境台账的环境由外层选择，环境调整集中在服务器专页；手动筛选保存后从最新快照重新选取。两项均经原审查者复核关闭。

## 验证与边界

修复后完整单元测试 16 个文件／64 项通过；访问入口与服务器、原有环境台账合计 10 条实际桌面流程通过，其中 4 条覆盖访问入口／服务器、全部／通用筛选下的连续环境与账号编辑，以及保存过程中再次手动筛选。类型检查、生产构建和 diff 空白检查通过。
