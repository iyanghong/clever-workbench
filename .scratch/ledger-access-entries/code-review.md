## Spec

发现 P1：更改访问入口或服务器环境后马上编辑账号，环境保存使账号组件重挂载，静默丢失尚未自动保存的输入。真实 Electron 回归先复现用户名仍为旧值，再验证稳定组件身份及筛选保留当前记录的修复。

复核补充两条路径：P1，服务器专页改变资源类型会使记录退出列表；P2，手动筛选完成保存后读取旧闭包，撤销用户筛选。服务器专页现固定类型，环境台账的环境由外层选择，环境调整集中在服务器专页；手动筛选保存后从最新快照重新选取。两项均经原审查者复核关闭。
