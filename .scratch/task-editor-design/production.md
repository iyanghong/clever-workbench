# Vditor IR 正式接入

2026-10-21，用户明确授权替换正式编辑器、提交推送代码并发布 GitHub Release。接入覆盖共享 Editor，因此工作任务与文档一起生效。

## 实现边界

- Vditor 固定 4.0.1。`scripts/vditor.ts` 在构建时应用三个源文件的撤销补丁，保留 200 ms 连续输入分组。执行撤销或重做前同步提交未入栈的内容；光标标记和取消组合不清空重做。版本或源码锚点不匹配会直接停止构建。
- 构建沿用上游 TypeScript 字段赋值语义，避免子类声明覆盖继承来的 DOM 字段。生成文件放在 node_modules 缓存和被忽略的 public 目录，不修改依赖安装内容。
- Lute、中文语言包、图标和样式随包分发。保留生产 CSP，不使用 CDN、远端上传和本地缓存。Vditor 销毁时移除的共享图标脚本由应用恢复。
- Markdown 继续作为正文唯一权威来源。旧 JSON 字段维持兼容；无法用旧节点格式表示的合法内容（例如文字内的本地图片）使用空 JSON 缓存，Markdown 原文保留。无需数据库迁移。
- 打开记录先检查允许的 Markdown 结构，再比较 IR 转换前后的语义。外部图片、HTML、脚注、公式或有损转换继续留在源码页。仅打开、移动光标或失焦不重写原文。
- 编辑事件即时更新待保存内容；最终保存等待图片任务并再次读取编辑器，中文候选词未确认时阻止保存退出。保存失败维持原页面和重试入口。
- 文件、剪贴板截图与拖放统一走原有本地图片校验和导入 API。文件优先于剪贴板 HTML；导入前记录撤销边界。导入期间短暂锁定当前正文，保留插入点；完成后恢复输入，切换记录和退出必须等待。这是本次明确采用的简单可靠实现，未实现导入时并行输入的选区映射。
- 任务标题前置，系统和开始时间保持可见；计划与颜色标签可展开，摘要显示已设计划和标签。格式工具栏按需展开，正文使用应用主题，移除整块蓝色焦点框。保留键盘焦点提示、源码编辑、表格操作、本地图片预览和只读模式。

## 验证范围

自动回归包含：快速撤销、连续输入分组、多步重做、新分支丢弃旧重做、Chromium 中文组合与取消、语法显隐、图片撤销重做、延迟导入后导航、关闭后恢复、源码保全、表格约束、保存失败重试、任务和文档共用、主题和最小窗口，以及原有导出、备份与更新测试。

原生 macOS 输入与安装包结果、测试数量和发布链接在完成验证后补充。尚未将 Windows 原生输入法、第三方输入法和超长文档性能计为通过。
