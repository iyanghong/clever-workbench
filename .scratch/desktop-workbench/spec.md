# Clever Workbench 首版需求规格

Status: ready-for-agent

确认日期：2026-10-18。

实施授权：用户于 2026-10-18 明确要求创建持续目标并直接开始编码，按已确认规格和 23 项任务自主执行直到完成。此前“仅保留文档”的限制已解除。

## 问题陈述

用户是一名技术负责人，需要长期维护多个系统。这些系统会持续迭代多年，所属项目随阶段变化；系统又有不同环境、多个服务、Redis 和服务器等资源，以及超管、业务角色等不同用途的账号。资料容易散落在表格、聊天和文档里，查询生产环境账号、追溯历史项目、记录排障方案都需要反复查找。

用户还需要快速记录和完成个人任务，并按月或项目回顾工作。繁重的表单、重复填写系统与环境、强制安排日期都会增加工作负担。现有 Clever Plan 已覆盖大部分任务功能，但尚无完整的技术台账、凭据保护、独立文档和统一模块入口。

用户希望在 Mac 和 Windows 上使用同一套个人桌面工具，离线保留资料，通过备份迁移设备，并能持续加入新的效率工具。

## 解决方案

建立以“查账号、记方案、处理任务”为中心的本地个人工作台。首页提供常用系统和账号入口、未完成任务与最近文档；通过全局搜索和快速新建直达工作，减少表单与页面跳转。

系统保持长期身份，项目承载阶段工作。服务公共信息只维护一次，部署信息按环境记录；账号可以属于系统环境或具体资源。名称即可建立主要台账对象，任务只需标题，文档可以先写后归类。操作从已有对象发起时自动带入明确的上下文，用户可以修改。

任务与文档共用支持即时排版、Markdown 源码切换、表格和图片的编辑器。密码、Token、私钥使用专门的秘密字段，本机按需解锁；完整备份整体加密，可在另一平台恢复。界面采用 macOS 27 的设计语言，Windows 使用本平台的窗口操作与快捷键习惯。

8. 作为个人用户，我希望界面支持浅色、深色和跟随系统，以便适应不同工作环境。

65. 作为个人用户，我希望秘密锁定时仍可使用普通台账、任务、文档和图片，以便解锁策略不妨碍日常工作。
66. 作为个人用户，我希望明确知道忘记主密码且无可解锁副本时无法恢复秘密，以便自行妥善保管恢复所需信息。
67. 作为个人用户，我希望能够更改主密码，并知道旧备份仍使用生成时的密码，以便更新保护设置时不误判历史备份的恢复方式。
68. 作为技术负责人，我希望密码、Token 和私钥有专门的秘密输入位置，以便与不会自动加密的普通备注和正文区分。

73. 作为个人用户，我希望尚未设置主密码时明确看到备份未启用，以便不会误认为已有可用备份。
74. 作为个人用户，我希望恢复前看到通过验证的备份时间与记录数量，以便确认选中了正确资料。
75. 作为个人用户，我希望确认整份替换后先保留恢复前副本，再切换资料库，以便恢复操作有回退余地。

77. 作为个人用户，我希望备份保留草稿和可恢复删除内容仍引用的附件，以便恢复后的资料与恢复能力保持完整。
78. 作为个人用户，我希望能看到最近备份结果、失败原因并重试，以便及时发现实际没有完成的备份。
79. 作为个人用户，我希望新工作台独立保存资料，不写入旧 Clever Plan 的资料库，以便安全地使用新应用。

## 实施决策

### 产品范围与平台

为管理多个系统的技术负责人提供个人桌面工作台，减少查找资料、填写表单和切换工具的时间。核心动作是查生产环境账号、记录排障方案、创建与完成工作任务。

- 支持单人离线使用，资料保存在本机，通过加密备份在设备间迁移。
- 首版交付目标为 Apple Silicon Mac 和 Windows 11 x64；当前可用 Mac 为 macOS 27.0.1。
- 复用 Clever Plan 的功能和代码，无旧用户数据迁移需求。
- 使用 Electron、React、TypeScript、SQLite；后续通过新增内置模块增加效率工具。
- 首版范围不含多人协作、自动同步、第三方插件市场、批量表格导入、未来排期和工时管理。

### 模块与公开接口

- 应用外壳负责导航、搜索、快速新建和当前上下文；项目与系统负责稳定身份及关联；技术台账负责环境、服务、资源和账号元数据；任务负责状态与回顾；文档负责正文和关联。
- 共用编辑能力处理正文、源码切换、草稿及图片；秘密保管处理主密码、会话、查看与复制；数据能力处理事务、版本迁移、附件及完整备份恢复。
- 沿用现有受限桌面查询与操作的交互边界。普通接口返回对象元数据、查询结果或操作结果；秘密查看与复制为明确的独立操作，不能混入普通快照或列表。
- 内置模块登记稳定标识、名称、图标、页面入口及快捷操作；需要检索时提供包含对象类型、标识、标题、所属上下文和定位信息的结果。应用外壳组合入口，业务行为保留在各自模块。
- 保持单仓库、单应用，不为每个模块引入独立服务或发布流程。新应用采用独立产品身份、资料目录、附件协议和备份格式，不写入旧 Clever Plan 的资料库。

### 数据与保护约束

- 为项目、系统、环境、服务、环境部署、资源、账号、秘密、任务、文档和附件建立稳定身份与必要关系，管理统一的资料版本迁移。每个系统至多标记一个当前项目。
- 重命名不改变身份。归档与回收站保留关联；存在引用的父对象不能未经处理就级联物理删除。
- 正文保持单一权威版本，以 Markdown 正文承载保存与源码编辑，富文本作为编辑表示。原 Tiptap 配置是复用起点，不能认为已有源码切换和表格支持；补齐转换、编辑结构和持久化校验后再验收。
- 图片格式、大小、路径在桌面可信侧验证。备份包括资料、草稿和可恢复删除内容仍引用的附件。
- 主进程验证来源与参数，持有解锁会话材料；普通查询不返回秘密，复制秘密由桌面可信侧完成，锁定撤销秘密访问和显示状态。
- 使用成熟的密码派生与认证加密原语、随机盐、唯一 nonce 和版本化参数，按目标硬件校准；具体算法参数在实现阶段验证，不将尚未实现的加密视为已经完成。
- 秘密解锁材料与自动备份材料分开，后者不能绕过主密码取得秘密解密能力。便携恢复材料受主密码保护，不仅依赖旧电脑的系统密钥。
- 恢复在隔离空间验证密码、认证完整性、结构、版本与附件，对不可信大小和参数施加边界；通过验证后才允许确认替换。

### 沿用的任务边界行为

- 修正过去的开始或完成时间时保留创建时间；完成不得早于开始，未来排期不进入此模型。
- 归档项目中的任务需要重开时，明确执行恢复项目与重开。未完成任务从回收站恢复到已归档项目时，提供恢复项目或改为未分类的明确选择。
- 跨月任务可计入各月涉及数，但只计入完成所在月的完成数；同日任务仍可见并可定位，回收站内容不计入日常回顾。

### 页面入口与高频流程

左侧固定“工作台、台账、任务、文档”，底部放设置。顶部提供全局搜索与快速新建。启动默认打开工作台，展示常用系统和账号入口、未完成任务、最近文档。首个效率工具加入时启用“工具箱”入口。

项目是贯穿页面的工作背景，不为每个项目复制一组功能入口。台账内先选系统，再切换环境；详情在当前页面内展开，减少来回跳转。

**查账号**

输入“系统 A 生产 Redis”等关键词，结果展示系统、环境、资源与账号用途。选中结果即可打开详情或复制用户名；复制秘密时按需解锁。结果中始终显示环境，帮助区分生产与测试。

**记方案**

快速新建文档后直接编辑，支持粘贴截图并自动保存。没有项目或系统归属时也能记录；在已有对象页面发起时带入明确的上下文，之后可以调整。

**处理任务**

输入一行标题并回车即可创建任务。项目、正文和日期均可后补。列表一键完成，记录当前时间并提供撤销；需要写过程时打开共用的 Markdown 编辑器。

### 系统、项目与技术台账

**长期系统与阶段项目**

系统保持稳定身份，可跨多个阶段项目。保留系统与历次项目的关联，另标当前项目。由 A 项目切换到 B 项目时，系统台账继续使用原记录，旧项目的任务和文档归属保持不变。

首版各系统独立管理环境、服务和资源。名称即可建立系统或项目，说明、链接及项目关联按需补充。

**常用对象与字段**

| 对象 | 快速创建 | 可选信息 |
| --- | --- | --- |
| 系统 | 名称 | 说明、常用链接、当前项目 |
| 环境 | 名称，提供开发／测试／生产候选 | 说明 |
| 服务 | 名称 | 代码仓库、说明；不同环境的部署信息 |
| Redis | 名称 | 地址、端口、备注、多个账号 |
| 服务器 | 名称 | IP 或主机名、SSH 端口、备注、多个账号 |
| 其他资源 | 名称与类型 | 地址、链接、按需添加的普通字段、备注 |
| 账号 | 用途或角色标识 | 用户名、密码／Token／私钥、说明 |

普通字段均可后补，不通过完整性评分或必填长表单催促填写。账号用户名允许为空，以覆盖只使用 Token 或密码的场景。

系统环境和具体资源下均支持多个账号。例如“系统 A／生产”下有超管、B 角色账号，Redis 和服务器又各有自己的访问账号。普通页面中的角色只是账号用途，不是工作台的多用户权限体系。

支持快捷新建、行内编辑、复制条目及普通字段的一键复制。复制条目默认复制非秘密字段；需要复制秘密时，明确选择并解锁。备注不会自动变成加密字段，秘密使用专门的输入位置。

### 任务与项目归档

- 任务默认生成创建时间与开始时间，开始时间可修正；未完成时完成时间为空。
- 一键完成取当前时间，沿用现有分钟级时间口径；重复点击不会重写已有完成时间。
- 任务最多归类到一个项目，也可留在未分类；支持未完成、已完成、全部和项目筛选。
- 重开任务清空当前完成时间，再次完成写入新时间。沿用当前状态统计，不保存多轮执行历史。
- 支持项目归档、恢复及任务回收站。项目归档与任务归类是两种独立操作。
- 甘特图提供月度和项目回顾，从开始时间画至完成时间；未完成延伸到当前时刻。跨月任务按查看区间裁切。
- 时间跨度用于回顾，不表示实际工时。重开、修正日期或删除会更新相应统计。

### 技术文档与共用编辑器

文档可以独立创建，也可从系统、环境或资源页面快速创建。任务正文与文档使用同一编辑能力和图片处理方式。

- 默认即时排版，可以切换到 Markdown 源码。
- 支持标题、段落、粗斜体、链接、引用、代码块与语言标识、普通列表、任务清单、常用 Markdown 表格和图片。
- 图片支持文件选择、拖入及剪贴板粘贴，导入为本地副本；原文件移动或删除不影响已保存内容。
- 自动保存草稿与编辑内容，展示保存状态；关闭详情、切换对象、退出应用前处理尚未保存的内容与图片。
- 采用单一正文版本，保证源码与即时排版不会各保存一份互相覆盖。格式标记可以规范化，内容不能丢失。
- 源码中出现无法安全转换的结构时，保留原文和源码编辑能力，说明限制，不静默删除后切换。
- 文档支持全文搜索、关联对象跳转与回收站。

### 秘密保护与备份迁移

**日常使用**

首次保存秘密或启用加密备份时设置主密码，普通记录可先使用。重启后第一次查看或复制秘密时解锁；普通名称、地址、任务、文档和图片始终可浏览。闲置 15 分钟、系统锁屏或退出应用时锁定，也提供手动锁定。

秘密默认遮蔽，解锁后仍需明确查看或复制。密码、Token、私钥不进入普通搜索、日志、错误提示或普通列表数据。复制秘密后默认 30 秒清理本应用写入的剪贴板内容，仅在内容仍未改变时执行，避免覆盖用户后续复制的内容。

本机只加密秘密字段；普通正文或图片中的敏感内容不会自动识别和加密。忘记主密码且没有可解锁副本时，不能恢复秘密。首版使用跨平台主密码体验，不依赖 Touch ID 或 Windows Hello。

**完整备份**

完整备份包括台账、任务、项目关联、文档、图片与必要设置，整体加密。恢复使用备份生成时的主密码，不依赖原电脑的系统密钥。

沿用原程序的自动备份节奏：有变更时每日一次，保留最近 7 份；可设置备份目录并随时手动导出。主密码设置后，自动备份应能在秘密锁定时运行，不要求用户为每次备份重新输入密码；此能力不应绕过秘密解锁。

尚未设置主密码时，备份入口显示未启用，不将未执行的备份显示为成功。

恢复前先验证密码、完整性、版本和附件，再展示备份时间与记录数量。用户确认整份替换后，保存恢复前副本，再切换到恢复后的资料。失败时保留当前资料库。更改主密码不改变旧备份使用的密码。

### 外观与桌面体验

以 [Apple macOS 27 设计套件](https://developer.apple.com/news/?id=e2lxw9l1) 和 [Liquid Glass 设计方向](https://support.apple.com/en-us/127257) 为依据。采用清晰分栏、精炼工具栏、克制的色彩与材质、明确的字体层级。玻璃效果主要用于导航和操作层，表格及长文正文保持稳定底色与清晰对比。

首页突出可操作内容，不以大量统计数字占据首屏。台账字段在需要时展开；常见动作靠近内容，避免每次编辑都进入独立大表单。

支持浅色、深色和跟随系统；键盘操作、焦点状态、减少透明度与减少动态效果纳入验收。Mac 与 Windows 使用一致的应用语言，窗口按钮、系统菜单及快捷键遵循平台习惯。

### 模块扩展

新模块接入统一的导航、搜索与快捷操作，复用编辑器、附件、数据访问和备份能力。系统、项目、任务和文档各自保有稳定身份，跨模块通过明确引用关联。

新增工具应主要修改新模块和一处入口登记，避免将业务继续堆入单个页面组件。首版不实现动态插件加载或插件市场。

### 已确认的关系规则

以下三条关系规则已经在 Q20 随整体方案确认。

| 规则 | 确认行为 | 示例 |
| --- | --- | --- |
| 同一服务跨环境 | 代码仓库等服务公共信息只录一次；部署地址、端口等按环境分别记录 | 订单服务共用一个仓库，测试与生产各有部署地址 |
| 任务与文档关联 | 从对象页面新建时带入系统／环境／资源和当时的项目；允许取消或修改。后续系统换项目不会自动改写旧记录 | 在 A 项目期间写的 Redis 排障方案继续归属 A，并可从长期系统页面找到 |
| 项目归档的影响 | 项目有未完成任务时先处理或转移任务；归档只收起阶段项目，不冻结长期系统、环境、账号或文档。若它是当前项目，清除当前标记但保留历史关联 | A 项目结束后仍能维护系统和查询生产密码 |

## 测试决策

### 验证边界与方法

沿用用户已确认技术方案中的测试边界，以桌面应用公开操作和用户可见结果为主要验收面。参考程序已有受限桌面查询与操作接口、存储与备份公开接口，以及 Electron 端到端测试；优先沿用这些边界，不为测试增加一组穿透内部实现的接口。

集成测试从公开查询和操作调用真实的临时 SQLite 与附件目录，检查持久化、重启、失败前后资料和调用方可见错误。桌面端到端测试从页面完成三条高频流程，检查真实保存、图片、剪贴板、锁定和恢复结果。只在需要控制时间或注入故障时使用现有可控位置，不以内部调用次数、私有函数、组件树或 SQL 文本作为业务正确性的依据。

这遵循“优先复用已有边界、在尽可能高的层级测试”的原则。前次整体确认已经包含技术方案与验收范围，本次将其整理为明确标准，不再进行需求访谈。

### 覆盖范围与通过条件

| 编号 | 被测能力 | 可观察的通过条件 |
| --- | --- | --- |
| T01 | 应用外壳、轻量录入 | 三条高频流程可从统一入口完成；任务只填标题、台账只填名称、文档先写后归类；中文输入组合过程不误提交 |
| T02 | 系统与项目 | 同一系统跨 A、B 项目后身份不变，历史关联和旧任务、文档仍可查询；改名不破坏引用 |
| T03 | 服务、环境、资源、账号 | 服务公共仓库只维护一次，各环境部署独立；环境及资源各可有多个角色账号，空用户名合法，结果环境明确 |
| T04 | 上下文与复制 | 新记录带入明确的对象与当时项目，允许修改；复制条目不默认复制秘密；系统换项目不批量修改旧记录 |
| T05 | 任务状态和时间 | 创建时间稳定，重复完成不改写完成时间，撤销和重开一致；不接受完成早于开始的状态 |
| T06 | 项目归档与回收站 | 未完成任务阻止归档；归档不冻结台账，清除当前项目标记并保留历史；恢复与重开的项目状态一致 |
| T07 | 月度和项目回顾 | 跨月、同日、未完成、重开、日期修正和删除的时间条与计数正确；涉及数与完成数使用不同口径 |
| T08 | 共用编辑器 | 表格、代码块、清单和本地图片在源码与即时排版之间保持内容；不支持结构仍可从源码恢复，不静默删除 |
| T09 | 草稿、图片与退出 | 粘贴图片后立即关闭详情、退出或重启，内容及引用保持；原图移动不影响查看；导入失败有明确结果且不破坏已有内容 |
| T10 | 搜索与对象定位 | 中文、相似名称和通配字符正确处理；结果能定位对象，回收站不混入普通搜索；秘密不出现在结果或普通快照 |
| T11 | 秘密保管与会话 | 错误密码无法查看或复制秘密；正确解锁、闲置 15 分钟、锁屏、手动锁定和重启行为一致，普通资料仍可用 |
| T12 | 秘密复制和保护范围 | 秘密默认遮蔽；30 秒后只清除未改变的本次剪贴板值；持久化资料、普通日志及错误中不出现秘密明文 |
| T13 | 完整加密备份 | 草稿、回收站引用、关系、正文与图片完整往返；秘密锁定时可备份但不能借此解锁；主密码未设置时不显示成功 |
| T14 | 恢复失败与密码变更 | 错误密码、篡改、缺失附件、不支持版本、受限参数和切换失败都保留当前资料；变更密码后旧备份仍按原密码恢复 |
| T15 | 自动备份 | 有变更才按每日节奏备份，保留最近 7 份；失败可见并可重试，恢复前副本不被误当作成功的新资料 |

| T17 | 模块接入与新应用身份 | 台账、任务和文档通过同一入口、定位与公共能力工作；新应用操作不改动旧 Clever Plan 的资料 |

测试使用临时资料库和虚构凭据。界面样式通过实际桌面查看与必要的视觉核查确认，不为静态样式和简单字段映射编写镜像式测试。Windows 构建成功不替代 Windows 运行验收；Mac 与 Windows 的双向恢复必须实际验证。

### 可复用的先例与证据范围

Clever Plan 的现有存储和备份测试已覆盖创建时间保留、归档重开约束、搜索通配字符、图片格式、草稿重启、跨月统计、完整备份往返、损坏备份拒绝、资料切换失败及大量任务查询。已有 Electron 端到端测试覆盖任务项目生命周期、主题、草稿、图片粘贴、备份恢复和重启，可作为新增流程的基础。

此前调查运行过 1 个测试文件、9 项单元测试，全部通过，并用转换探针发现现有 Markdown 配置不支持表格且存在往返规范化。这些是参考程序的调查证据；新工作台尚未实现，本次仅校验规格文档，不表示新的业务、加密或 Windows 运行测试已经通过。

- 多人协作、在线账号体系和跨设备自动同步。
- 跨系统共享资源；首版资源分别归属于各系统环境。
- 第三方插件市场、动态插件加载和无代码工具搭建。
- Excel、CSV 批量导入，以及旧 Clever Plan 用户资料迁移。

- 未在规格中约定的在线服务部署和额外产品功能。
