## Standards

未发现违反 AGENTS.md、领域术语或 ADR 的硬性问题。两项 Duplicated Code 判断项：

1. [P2] 任务列表另写快捷草稿保存队列。定时保存失败后只等待旧的拒绝结果，必须修改文字才重新入队。现已保留脏状态，并在每次 flush 中串行重试最新内容；真实 SQLite 故障下，不改文字即可重试导航并恢复草稿。
2. [P2] 备份预检与正常草稿写入的校验规则分歧。`startedAt=-1` 可恢复，却无法创建任务。现已共用 `validateDraftFields`，同时用于正常写入、备份草稿、任务和文档；时间、长度、正文结构及非 null 的无效草稿均受校验。
