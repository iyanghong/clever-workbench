## 已明确的需求

- 产品为个人工作台桌面程序，同时支持 macOS 和 Windows。
- 面向管理多个项目、系统的技术负责人，减少重复操作和表单录入时间。
- 技术台账覆盖系统信息、不同环境的账号信息，以及微服务场景下各服务的信息。
- 支持快速新增技术文档，以 Markdown 编辑器记录问题与方案。
- 工作任务模块参考本机 `/Users/axelton/code/clever-plan` 的现有实现。
- 任务列表支持按项目归档、一键完成；点击完成时记录当前时间。
- 新任务默认记录创建时间，不强制填写完成时间；工作内容使用 Markdown 编辑器，支持上传与粘贴图片。
- 统计支持按月或按项目查看甘特图。
- 后续可持续添加提高个人工作效率的功能，技术封装与页面入口应支持这种扩展。
- 界面采用用户所称的“macOS 27 设计美学”，具体视觉语言与平台适配待对照公开资料确认。

## 已确认的编辑与低录入负担方案

以下交互建议已随 Q20 的整体方案确认：

- 系统、项目、服务和资源以名称完成初次创建，其余属性可以后补；当前上下文明确时自动带入系统、环境或项目。
- 任务保留一行快录与一键完成。文档快速进入编辑器，未分类内容可以先保存，再补关联。
- 台账以紧凑列表与详情展示常用字段，增加可选备注；多角色账号按用途区分，不引入工作台多用户权限体系。
- 一个全局搜索入口检索普通信息，搜索结果直接定位目标；密码、Token、私钥不进入普通搜索内容。
- 任务与技术文档共用编辑器、图片和自动保存能力。源码切换应保留内容语义，支持常用 Markdown 与表格；遇到无法表示的内容时保留原始源码，不能静默删除。
- macOS 27 视觉风格应用于导航、工具栏与操作浮层，密集资料和正文保持可读性；Windows 保留本平台的窗口操作和快捷键习惯。
