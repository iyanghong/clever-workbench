## 验收标准

- [x] Redis、服务器及其他资源可以用名称和默认类型快速建立；地址、端口、SSH 信息、说明及附加普通字段可后补。
- [x] 资源稳定关联所在系统与环境，首版没有跨系统共用同一资源的入口；目标归属在创建和复制时可见。
- [x] 列表或详情可直接修改常用字段，保存与错误状态明确，重启后保持修改。
- [x] 复制生成新身份，保留所选非秘密信息并允许修改名称和归属；不会修改源条目，也不会默认复制任何秘密。
- [x] 用户名之外的地址、端口等普通值可一键复制，明确的资源链接可打开；不把资源字符串当成任意系统命令执行。
- [x] 增加或删除附加普通字段不要求所有资源采用统一长表单，备注与秘密字段的保护范围区分清楚。
- [x] 改名不破坏定位，有引用的删除请求不产生悬空关系；公开行为测试覆盖复制、持久化及无效输入失败。

## 演示与验证

在生产环境建立 Redis 和服务器，补上地址与端口，再复制 Redis 条目用于新资源并编辑差异。

通过真实本地持久化和界面操作验证两类资源；剪贴板与外链使用受控桌面能力。
