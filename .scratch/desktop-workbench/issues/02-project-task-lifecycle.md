## 交付行为

把任务归类到项目，筛选、修改、完成、撤销、重开、删除和恢复任务，保留准确的创建与业务时间。

## 本任务边界

本项建立项目与任务的完整日常操作；项目归档及其对系统、文档的影响由任务 10 交付。

## 验收标准

- [ ] 项目只填名称即可创建，支持修改名称和颜色；任务最多归类到一个项目，也可保持未分类。
- [ ] 列表按未完成、已完成、全部及项目筛选，修改归属后结果立即一致，重启后保持。
- [ ] 完成提供撤销；重开清空当前完成时间并保留开始时间，再次完成写入新时间。
- [ ] 修正过去的开始或完成时间不改变创建时间；拒绝完成早于开始以及未来排期数据，失败不破坏已有记录。
- [ ] 任务删除进入回收站，恢复保留内容、标识与时间；在普通列表和普通查询中排除回收站记录。
- [ ] 修改、状态变化和恢复使用一致的公开操作，失败有明确结果，不让界面与持久化状态各自显示不同事实。
- [ ] 用公开查询与操作覆盖重复完成、撤销、重开、未分类、日期修正和回收站恢复，沿用原程序的相关约束测试。

## 演示与验证

创建 A 项目，将任务归入项目，筛选未完成任务，完成后撤销，修正实际开始时间，再删除和恢复。

以已有任务状态与时间测试为先例；本项不以内部函数调用次数或界面组件结构作为正确性依据。
