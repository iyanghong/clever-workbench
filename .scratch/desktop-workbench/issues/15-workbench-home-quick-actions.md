## 交付行为

默认打开覆盖三个高频动作的工作台，展示常用系统和账号、未完成任务、最近文档，并在各主要页面快速新建。

## 前置依赖

- [14：全局搜索与结果直接操作](14-global-search-actions.md)：首页与快速操作需要已有模块对象、全局搜索和账号直接操作，才能呈现真实的高频工作入口。

## 本任务边界

交付已有模块的统一日常入口，不新增空工具、插件市场或与用户任务无关的统计看板。

## 验收标准

- [x] 启动默认进入工作台，呈现真实常用对象、未完成任务和最近文档，空数据时仍提供可用的快速操作。
- [x] 侧栏固定工作台、台账、任务、文档，设置在底部；顶部搜索和快速新建在主要页面始终可达。
- [x] 常用对象的选择与排序、必要首页偏好持久化；被删除或失效对象不留下不可解释的入口，秘密本身不出现在常用列表。
- [x] 从首页或其他页面创建任务、文档及台账时继承明确上下文，用户可修改；缺少归属时允许先保存。
- [x] 新建和搜索动作通过已有模块登记与对象定位接入，新增模块主要增加自身能力与一处登记，不把业务重新集中进首页。
- [x] 没有实际工具时不出现空工具箱；首个工具可以通过相同入口方式加入，不建立第三方插件加载机制。
- [x] 键盘顺序、焦点返回和快速连续操作可用，三条高频流程均能从首页开始并看到持久化结果。

## 演示与验证

固定生产系统与账号，重启后从首页复制账号、创建任务、打开最近方案；从资源上下文快速新建文档。

用已真实实现的台账、任务、文档作为多个模块，验证统一入口契约，不为证明扩展性额外实现无关工具。


## Answer

启动默认工作台，常用系统／账号可选择、排序和复制，待办可快速完成并撤销，最近文档可直接打开。全局新建通过模块 actions（组件或即时创建）登记，系统／环境／资源及任务／文档发布背景。已有草稿受到保护，独立新建不会清除正文。2 项常用对象／草稿存储用例、2 项首页及全新建路径 Electron 用例、原生桌面生命周期流程和 9 项存储回归通过；首页实际截图已核查。
