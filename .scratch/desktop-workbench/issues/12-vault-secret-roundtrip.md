## 交付行为

首次设置主密码，为一个账号安全保存密码、Token 或私钥；重启后按需解锁查看秘密，普通资料仍然可访问。

## 前置依赖

- [06：系统与资源下的多角色账号](06-multi-role-account-ledger.md)：需要有稳定归属和元数据操作的真实账号，才能贯通秘密输入、加密保存、查询和展示。

## 本任务边界

交付真实加密与按需查看这一完整路径，手动锁定和重启锁定在本项完成；剪贴板复制、闲置及系统锁屏策略由任务 13 接入，主密码变更由任务 19 接入。

## 验收标准

- [x] 首次保存秘密时引导设置主密码，普通资料无需先设置密码；主密码初始化可被未来备份设置复用，不要求先录一条真实秘密。
- [x] 密码、Token、私钥使用专门输入与持久化位置，普通账号元数据和正文不会自动成为秘密；默认遮蔽，查看需要明确操作。
- [x] 使用经过验证的密码派生和认证加密原语、随机盐及版本化参数；有效保存后可重启解锁读回，错误密码或篡改数据不返回秘密。
- [x] 主密码不以可直接读取的方式保存；普通快照、查询、搜索输入输出、错误和日志均不携带秘密明文或解密材料。
- [x] 解锁材料只在受控会话内使用，手动锁定或重启撤销秘密访问与显示；锁定后普通台账、任务和已接入文档仍可使用。
- [x] 查询和操作在可信桌面边界验证来源与参数，绕过界面直接请求秘密时同样执行锁定检查。
- [x] 明确说明忘记主密码且无可解锁副本时不能恢复秘密，不提供绕过主密码的普通查询入口。
- [x] 以虚构秘密验证保存、更新、重启、错误密码、篡改、手动锁定及明文泄漏检查；算法参数需在目标硬件验证后记录。

## 演示与验证

为生产 Redis 账号保存虚构密码，关闭重启后先查看普通台账，再输入错误和正确主密码尝试查看秘密。

以公开的设置、保存、解锁、查看和锁定行为测试，不依赖界面遮蔽证明加密。为备份保留可移植的受保护恢复材料设计，不能仅用设备密文替代主密码。


## Answer

秘密使用独立主进程操作，AES-256-GCM 加密，随机盐及 scrypt N=131072/r=8/p=1 保护资料密钥。备份公私钥材料独立，未来锁定导出只使用公钥。支持密码／Token／私钥、主密码按需设置与解锁、遮蔽与手动锁定。3 项公开真实持久化测试覆盖错误密码、篡改、明文落盘扫描、重启及迟到解锁取消；Electron 流程覆盖设置、保存、查看、锁定、错误密码、重启及绕过 UI 的拒绝。实际 Electron 运行时派生耗时约 280–287 ms，见 vault-design.md。类型检查、构建与 4 项台账回归通过。
