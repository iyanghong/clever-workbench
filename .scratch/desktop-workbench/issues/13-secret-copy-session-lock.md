# 13：凭据复制与会话自动锁定

Status: resolved
Blocked by: 12

当前阶段：任务拆分已确认。实施授权：用户已明确要求直接编码，按依赖自主执行至完成。

共用完成标准见 [拆分总览](../ticket-plan.md)。

需求依据：[正式需求规格](../spec.md)；用户故事 US-26、US-60、US-61、US-62、US-63、US-64、US-65；测试场景 T11、T12。

## 交付行为

按需解锁后直接复制秘密，连续操作不重复询问；闲置、锁屏、退出和手动锁定后恢复保护，并管理本次秘密剪贴板。

## 前置依赖

- [12：主密码与凭据加密保存查看](12-vault-secret-roundtrip.md)：必须先有真实加密、主密码与受控解锁会话，才能安全复制秘密并验证锁定不会被绕过。

## 本任务边界

补齐会话和操作体验，所有秘密操作共用同一访问检查；不引入 Touch ID、Windows Hello 或后台自动解锁。

## 验收标准

- [x] 首次查看或复制时按需解锁，会话有效时不重复询问；解锁后秘密仍默认遮蔽，不自动展开所有账号。
- [x] 无用户操作 15 分钟、系统锁屏、退出或手动锁定均撤销秘密访问与显示，普通内容保持可用。
- [x] 复制秘密通过受控桌面操作完成，锁定时直接调用同一操作也被拒绝，取消解锁不复制任何旧值。
- [x] 复制后默认 30 秒仅清理仍等于本次复制值的剪贴板；用户后来复制的其他内容不被清理，多次复制的计时不会互相误清。
- [x] 账号或资源复制默认不带秘密；明确选择复制秘密并解锁时才生成目标秘密记录，失败不留下误以为已复制的条目。
- [x] 错误、取消、计时和系统事件不把秘密写入日志、提示或普通状态，锁定后的待完成操作不能继续泄漏秘密。
- [x] 用受控时钟和真实桌面事件边界验证闲置、锁屏、退出、重复复制和取消；分别记录目标平台事件的验证证据。

## 演示与验证

复制一个账号密码，复制普通文字后等待清理时限，确认普通文字保留；随后锁屏或模拟闲置，再次复制必须重新解锁。

复用任务 12 的秘密访问检查，添加可观察的会话与剪贴板流程；不宣称能清除操作系统或其他应用持有的全部历史副本。


## Answer

秘密复制留在主进程；15 分钟闲置、锁屏、休眠、退出与手动锁定共用会话撤销。异步剪贴板以队列和代次保护迟到写入，30 秒只清理仍持有的秘密。账号／资源显式勾选后可原子复制秘密，取消解锁不创建副本。4 项受控时钟／异步写入／事务失败测试通过；3 项 Electron 流程通过，包含真实等待 30 秒、实际剪贴板、主进程 powerMonitor 锁屏事件边界和取消操作。macOS 已验证，Windows 事件运行证据随任务 22 验收补齐，不将模拟事件称为实际操作系统锁屏。
