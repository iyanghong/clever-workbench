## 验收标准

- [x] 系统只填名称即可建立，说明与常用链接可后补；从台账入口可以查看并修改系统。
- [x] 系统和项目具有独立稳定身份，每个系统至多有一个当前项目，可保留多个历史关联。
- [x] 将当前项目从甲切换到乙时保留甲的历史关联，系统标识不变；切换为无当前项目也不会删除历史。
- [x] 从系统中创建任务时可带入系统及当时的当前项目，用户可以修改或取消关联；无当前项目时允许先保存。
- [x] 切换当前项目不会批量修改已存在任务的项目归属；系统与项目改名后关联和定位继续有效。
- [x] 相关关系和修改持久化，重启后可追溯；重复关联、非法目标或有引用的删除请求不会造成悬空引用。
- [x] 通过公开操作重放甲、乙两个项目的场景，检查历史记录、当前标记和任务查询结果。

## 演示与验证

创建系统 A，当前项目设为项目甲，记录一条相关任务；改为项目乙，检查系统仍是同一条记录且旧任务仍归甲。

遵循系统身份独立于阶段项目的 ADR；验证业务关系，不绑定具体关联表的物理设计。
