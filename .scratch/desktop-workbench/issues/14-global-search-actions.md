## 本任务边界

## 验收标准

- [x] 统一搜索入口覆盖系统、资源、账号元数据、任务与文档普通内容，中文关键词和相似名称可正确检索。
- [x] 结果展示类型和所属系统、环境、资源或项目，环境差异明确，重名对象可区分。
- [x] 结果点击定位正确对象，复制用户名或秘密调用现有受控操作；需要解锁时保留当前结果与操作意图。
- [x] 秘密字段、主密码、解密材料不进入索引、搜索结果、错误或普通快照；用已保存的虚构秘密查询也不能搜出明文。
- [x] 普通搜索排除回收站内容；重命名、修改正文、恢复和归属变化后结果与当前资料一致。
- [x] 搜索不把通配字符解释为扩大结果的任意模式，空结果、取消和快速连续查询不显示过期结果。
- [x] 键盘可打开搜索、移动结果、执行与返回；通过桌面流程验证从查询到打开或复制的完整路径。

## 演示与验证

搜索“系统 A 生产 Redis”，打开匹配账号并复制；再搜索排障文档中的中文内容，从结果回到文档和资源。

沿用原中文与通配符搜索用例，覆盖跨模块内容及任务 12 实际保存的秘密排除；验证的是结果和动作，不固定底层索引技术。


## Answer

全局搜索覆盖系统、环境、服务公共信息、资源、账号元数据、任务和文档，普通内容即时查询，不建立秘密索引。结果带背景，可复制用户名或复用按需解锁的秘密复制；对象类型通过模块登记定位。真实桌面流程通过快捷键、结果复制、嵌套解锁及键盘定位文档。补充红绿测试修复快速改词后 Enter 错开旧结果的问题。公开存储用例验证中文组合、字面通配符、秘密排除、回收站和重命名。类型检查与构建通过。
