## 本任务边界

本项交付实际 Mac 产物和运行证据，修复该平台发现的集成问题；首版不要求正式签名、公证或自动更新。

## 验收标准

- [ ] 产物以独立身份在目标 Apple Silicon Mac 安装、启动、退出和重启，离线不依赖开发服务或远程编辑资源。
- [ ] 在打包产物中完成三条高频流程、项目切换与归档、文档源码和图片往返、回顾定位，所有结果持久化。
- [ ] 主密码、手动与自动锁定、系统锁屏、秘密复制和剪贴板清理在目标 Mac 上实际有效，普通资料在锁定时可用。
- [ ] 完成手动备份、自动备份、错误密码拒绝和恢复前回退检查，导出可供 Windows 验收使用的虚构完整资料包。
- [ ] 实际检查浅色、深色、导航材质、文字密度、键盘焦点和减少动态效果，修复阻碍操作的视觉问题。
- [ ] 记录产物版本、目标系统、执行过的场景和结果；开发模式通过不能代替打包产物通过，未验证项不能标记完成。
- [ ] 运行与本次集成变更相关的已有回归检查，产物不包含真实凭据或用户资料，也不覆盖旧 Clever Plan。

## 演示与验证

基于实际 Mac 打包产物进行端到端与视觉验收，保留虚构备份和验证记录作为双向迁移输入。
