## 交付行为

在任务详情里编辑基础 Markdown、选择或粘贴截图，并在切换、关闭与重启后保留正文和本地图片。

## 前置依赖

- [01：独立桌面应用与任务快录](01-desktop-task-capture.md)：需要真实任务和桌面持久化入口，才能交付任务正文编辑与退出恢复。

## 本任务边界

先复用并封装现有图文与保存能力，使任务这一调用方完整可用；源码切换与表格由任务 08 交付。

## 验收标准

- [x] 任务正文使用共用编辑能力，支持已有基础格式、代码块及清单，正文保持单一权威版本并遵循 Markdown 保存约定。
- [x] 图片可通过文件选择、拖入、粘贴导入为受控本地副本，校验格式、大小和路径；原文件移动或删除后仍可查看。
- [x] 草稿与已保存正文自动保存并显示状态；切换对象、关闭详情和退出前协调保存队列与尚未完成的图片导入。
- [x] 快速连续编辑不会由迟到的旧保存覆盖新内容；失败时保留可恢复内容并明确说明，不伪装已保存。
- [x] 基础格式转换先限定可安全支持的范围，未支持的输入保留原文或给出可恢复处理，不能静默丢弃。
- [x] 复用能力对调用方只暴露加载、编辑、保存和错误结果；为独立文档保留同一调用方式，不另做一套图片存储。
- [x] 以隔离附件目录验证图片、草稿和重启；桌面流程覆盖粘贴后立即切换或退出、导入失败及再次打开。

## 演示与验证

打开任务写一段排障过程，粘贴截图后立即关闭详情并退出，重启检查正文和图片仍可查看。

沿用 Clever Plan 的图片导入、保存队列、退出握手和草稿测试；此处不宣称已完成表格或源码模式。


## Answer

共用编辑器改为以 Markdown 加载和保存，富文本仅作编辑表示。补齐表格、嵌套清单和源码模式；不安全转换保持原文且可重启恢复。任务与台账使用同一自动保存队列，图片导入纳入关闭／退出握手。7 项格式保全测试、3 项真实 Electron 编辑流程与 9 项存储回归通过；涵盖图片即贴即退、删除原图片、损坏图片、源码重启、实际 SQLite 写入失败后保留并重试。发现并修复了初始化可编辑状态触发错误正文保存的问题。类型检查与生产构建通过。
