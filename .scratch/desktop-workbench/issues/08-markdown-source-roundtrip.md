## 交付行为

在同一正文的即时排版与 Markdown 源码之间切换，安全编辑表格、代码块、清单和图片引用。

## 前置依赖

- [07：任务图文编辑与自动保存](07-task-markdown-images-autosave.md)：需要已真实用于任务的共用编辑器、正文保存和附件引用。

## 本任务边界

交付共用编辑器的完整转换行为，后续文档直接继承；不要求字节级保留所有 Markdown 标记写法。

## 验收标准

- [ ] 界面可以明确切换即时排版与源码，保存始终对应同一正文版本，不产生两份内容互相覆盖。
- [ ] 支持规格要求的标题、强调、链接、引用、带语言代码块、普通列表、任务清单、常用表格及本地图片。
- [ ] 补齐格式扩展、编辑结构与持久化校验，表格不因原有配置缺失被解析为空，支持结构往返后语义保持。
- [ ] 对不支持或无法安全转换的结构保留原始源码和编辑能力，说明限制，不以不完整转换覆盖原文。
- [ ] 允许规范化等价标记，但单元格内容、清单状态、代码语言、图片引用和段落不得静默丢失。
- [ ] 切换时等待或协调未完成的保存和图片导入，重启后保留最后成功保存版本，失败时可恢复当前源码。
- [ ] 通过公开编辑行为和桌面流程验证转换、保存、重启及失败分支，不仅比较内部编辑树结构。

## 演示与验证

在任务中写一张表格和带语言的代码块，切到源码修改，再切回并重启；再输入不支持的结构验证原文仍在。

将先前探针发现的表格丢失、混合列表与嵌套结构边界转为内容保全用例；复用现有基础格式和本地图片资料。
