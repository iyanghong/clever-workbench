本项交付手动导出与不修改当前资料的预检；真正替换恢复在任务 17，自动调度和保留策略在任务 18。格式独立于旧 Clever Plan，后续模块变更必须继续维护备份契约。

## 验收标准

- [x] 首次启用备份可以设置主密码，即使尚无秘密账号也可使用；未设置时显示未启用，不生成假成功记录。
- [x] 导出前协调待保存内容，使用一致资料快照，包含项目历史、台账、任务、文档、必要设置、草稿与可恢复删除内容引用的附件。
- [x] 完整输出整体加密，携带版本和受主密码保护的便携恢复材料；不以原电脑系统密钥作为唯一恢复条件，不把主密码或明文密钥附在备份中。
- [x] 秘密已锁定时仍可手动导出，备份过程不解锁或显示秘密；秘密解锁材料和备份材料保持分离。
- [x] 预检在隔离空间验证密码、认证完整性、资料结构、版本和附件，展示时间与记录数量，但不切换当前资料库。
- [x] 错误密码、篡改、缺失附件、异常大小或不支持版本被明确拒绝；对认证前的不可信参数也施加边界，失败清理临时工作。
- [x] 备份格式覆盖当前业务资料及必要偏好；后续有资料版本变化时同时更新迁移、备份和恢复兼容性验证，不固化为旧程序三张表。
- [x] 通过公开导出与预检行为验证锁定状态、草稿和图片包含、错误密码及损坏拒绝；实际跨平台恢复由交付验收验证。

## 演示与验证

在含任务、文档、账号、草稿和图片的工作台导出备份，锁定秘密后再次导出；用正确、错误密码分别预检。

复用现有一致快照、附件清单与预检测试方法，替换明文 ZIP 交付方式；不以能打开压缩包或哈希校验等同于加密。


## Answer

整体导出采用 CWBK0001 容器、RSA-OAEP-SHA256 与 AES-256-GCM，包含当前资料、草稿、回收站和引用附件；保护材料取自一致 SQLite 快照。锁定导出不解锁秘密。独立设置页完成首次主密码设置、导出、密码预检与取消流程。预检限定文件、头部、KDF、清单和解压大小，认证后才提取，并验证全部资料模型。4 项加密备份测试通过，包含错误密码、认证损坏、截断、异常参数与目录故障后的重试；原存储 9 项、文档 4 项备份回归及设置预检 Electron 流程通过。实际替换与失败恢复继续在任务 17 验证。
