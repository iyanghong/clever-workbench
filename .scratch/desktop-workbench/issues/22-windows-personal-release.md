## 本任务边界

Windows 与 Mac 产物可以并行验证。本项必须有实际 Windows 运行环境；仅在 Mac 交叉打包成功不能满足验收。

## 验收标准

- [ ] 在 Windows 11 x64 安装、启动、退出和重启打包产物，应用离线可用，不依赖开发服务；使用独立资料位置。
- [ ] 验证平台窗口按钮、系统菜单、键盘快捷键和中文输入组合，任务快录不因平台差异误提交。
- [ ] 完成台账、多角色账号、任务、文档、Markdown 源码、表格及图片选择、拖入和粘贴，结果重启后保持。
- [ ] 在 Windows 实际验证系统锁屏、闲置锁定、秘密复制及剪贴板清理；本机保护能力不能替代主密码要求。
- [ ] 验证路径、链接、文件选择、加密备份和恢复错误处理，导出可供 Mac 验收使用的虚构完整备份。
- [ ] 检查浅色、深色、字体、可读性、键盘焦点和减少动态效果，保持应用语言一致并保留 Windows 操作习惯。
- [ ] 记录产物版本、Windows 环境和实际结果；没有 Windows 环境时明确保持任务未验收，不将交叉编译当作通过。

## 演示与验证
