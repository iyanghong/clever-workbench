## 本任务边界

只复用和完善回顾跨度，不增加未来排期、任务依赖、里程碑或实际工时。

## 验收标准

- [x] 有月度与项目回顾入口，可切换查看月份与项目，时间条定位到对应任务。
- [x] 跨度从实际开始到完成；未完成延伸到现在，跨月任务按当前区间裁切，同日任务仍可见且可操作。
- [x] 跨月任务计入涉及的月份，但仅在完成所在月计入完成数；回收站记录不计入普通回顾。
- [x] 完成、重开、修正日期和删除后图表与计数反映当前有效状态，不使用旧缓存制造不同结果。
- [x] 图表明确说明跨度不代表实际工时，空状态、长标题和较多任务仍可阅读和操作。
- [x] 时间边界与月份采用统一口径，受控时钟测试覆盖月界、同日、未完成、重开和日期修正，桌面流程验证可点击定位。

## 演示与验证

创建跨月、同日和未完成任务，查看月度与项目回顾，再重开或修正一个任务，检查图表和计数随之更新。

优先沿用原时间计算与时间线行为测试；图表结果从公开任务记录计算，不另存一份独立统计事实。


## Answer

沿用既有回顾甘特图，不另存统计事实。新增固定时钟存储／计算用例，覆盖月界、同日、未完成、重开、日期修正与删除；Electron 流程验证月度计数、项目全貌、点击定位及重开后计数更新，均通过。图表保留“跨度不代表实际工时”说明与虚拟列表。
