## 交付行为

直接新建问题与方案文档，或从系统、环境、资源中带入创建时的背景；文档可查询、编辑、跳回对象和从回收站恢复。

## 前置依赖

- [05：资源台账与轻量复制](05-resource-ledger-copy.md)：需要系统、环境和具体资源，才能完整演示从对象创建文档并回到对象。
- [07：任务图文编辑与自动保存](07-task-markdown-images-autosave.md)：需要已经保存过真实正文和图片的共用编辑能力，避免再做一套存储和退出处理。

## 本任务边界

文档复用任务 07 的编辑接口；任务 08 的源码与表格增强独立推进并由共用编辑器继承。本项接入任务与文档的对象背景，跨模块搜索由任务 14 汇总。

## 验收标准

- [x] 文档入口可以直接开始编辑，标题或归属可后补，未分类文档也能保存与重启恢复。
- [x] 从系统、环境或资源新建任务或文档时带入明确对象和当时项目，用户可以修改或清除；对象背景不成为强制长表单。
- [x] 系统改当前项目后，已有文档和任务的历史项目归属不变，长期系统仍能查询相关资料并回到对象。
- [x] 任务与文档共用正文、图片、草稿、保存状态及退出协调能力，使用相同的内容与附件规则。
- [x] 文档列表支持普通内容查询和详情定位，单个文档可编辑、删除和从回收站恢复；普通列表排除回收站内容。
- [x] 关联对象改名后跳转仍有效，无效或已删除目标有明确处理，不因点击错误而破坏正文。
- [x] 验证跨项目前后关联、未分类文档、图片后立即切换、草稿重启和回收站恢复；不要求新建文档重新实现编辑底层。

## 演示与验证

在 A 项目的生产 Redis 页面写排障文档并粘贴图片，把系统切到 B 项目后，从系统和 A 项目都能找到原文档。

通过对象页面发起、编辑落盘、重启、查询及跳回对象组成完整桌面流程；直接复用已有图文保存用例。


## Answer

独立文档模块支持直接无标题写作、正文查询、源码及图片、回收站与恢复。系统、环境、资源可发起任务和文档；后台验证完整归属，创建时带入当前项目，详情可改关联并跳回对应对象。任务也扩展环境和资源外键。文档及源码图片引用已纳入现有备份校验。3 项公开存储测试、2 项 Electron 文档流程及 9 项存储回归通过，文档界面截图已检查。
