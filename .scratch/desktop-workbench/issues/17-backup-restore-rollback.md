从已验证的完整备份恢复工作台，确认前展示内容摘要，替换前保留原资料副本，失败时当前工作仍可继续。

## 本任务边界

交付用户可执行的恢复流程和故障回退，不把预检成功等同于恢复成功。两操作系统互换备份的最终证据在任务 23 完成。

## 验收标准

- [ ] 选择备份后在隔离空间验证，展示通过验证的时间与记录数量，再由用户确认整份替换；取消不修改当前资料。
- [ ] 恢复前协调现有编辑和待保存内容，创建可用的恢复前副本；只有全部验证成功后才切换到新资料。
- [ ] 恢复包含关系、时间、文档、账号、秘密密文、草稿、回收站引用和图片，恢复后查询与编辑结果一致。
- [ ] 使用备份生成时的主密码取得必要恢复能力，不依赖原电脑的系统密钥，也不要求存在原应用资料目录。
- [ ] 错误密码、认证失败、缺少附件、不支持版本或切换失败均保留原资料可用，不留下混合两份资料的状态。
- [ ] 切换后旧查询结果、待保存请求和旧解锁会话不能继续作用于新资料；当前页面与秘密会话使用新资料的状态。
- [ ] 恢复后的资料可以重启、再次导出并重新验证；预检到执行之间备份被更换时不得悄悄恢复另一份内容。
- [ ] 以故障注入和公开恢复流程覆盖取消、校验失败、恢复前副本失败及切换失败，不仅测试成功路径。

## 演示与验证

导出带图片和秘密的资料后修改当前内容，预检并恢复旧备份；再尝试错误密码、损坏包和切换失败，检查当前资料仍在。

沿用已有恢复分代切换和失败保留原库的先例，扩展到所有当前模型、附件和主密码材料。
