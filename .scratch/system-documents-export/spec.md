# 通用文档、系统任务与系统资料导出

Status: ready-for-agent

2026-10-19：用户要求继续优化，已确认密码也要导出，每份文档单独生成文件，另附系统总览；沿用既定 goal 的实施授权。

## 文档与任务

文档明确区分“通用文档”和“系统文档”。通用文档没有系统归属，系统文档属于一个系统；既有环境、资源及项目关联保留。文档页提供全部、通用、具体系统的筛选，列表显示归属，创建时继承所选范围，详情可直接修改系统归属。切换系统或清除关联时清除不再适用的环境、资源，项目按原有独立关联保留，不改写其他文档。已在编辑的文档改变归属后不能因退出筛选丢失内容；手动切换范围先保存。

任务的项目继续可选，系统关联直接可见。新增、快录和详情均能创建或编辑“只关联系统、不选项目”的任务，也保留仅记标题、尚无归属的任务。系统和项目不是互相替代的分类；系统换当前项目后，旧任务的项目不变。自动带入上下文时，用户可以明确清除项目。

## 系统资料导出

系统详情提供导出入口，支持 Markdown、Word（DOCX）和 PDF；用户选择一种或多种格式后导出一个 ZIP 资料包。每种格式分别包含系统总览及每份技术文档，文档标题重复时仍保留独立文件。关联任务正文也完整导出，避免仅有任务标题。图片使用包内文件或嵌入文档，不依赖应用专属协议或外部网络。

系统总览包括该系统基本信息、当前／历史项目关联、环境、服务公共信息及各环境部署、资源及服务器配置、访问入口的全部具名地址与常用选择、账号用途和用户名，以及相关任务和文档索引。包含该系统的未完成与已完成任务、有效文档及其创建时的关联信息；不把同项目下其他系统的资料混入，也不包含通用文档、回收站或未提交草稿。

用户明确要求导出账号密码。导出界面默认包含密码，需按既有机制解锁；Token 和私钥可另外明确选择。界面说明导出内容为明文，包含密码的资料包不属于加密备份。取消解锁或取消选择保存位置不生成文件，导出失败不留下误报成功的半成品。秘密只在主进程读取和生成文件，不经普通快照、日志或页面返回。

Markdown 保留正文结构，并改写本地图片引用；DOCX／PDF 保留标题、段落、列表、引用、代码、表格和图片。系统总览使用清晰的标题和表格，中文字体可读，长表格和图片不能超出页面。文件名兼容 Windows 和 macOS，防止重名覆盖、路径穿越及系统保留名。

导出前保存当前编辑及待导入图片，从一致的资料视图生成文件；不修改原资料。导出只用于阅读、交接和留档，不增加导入功能，现有整体加密备份和恢复保持独立。

## 验收

1. 通用文档、系统 A／B 文档可分别筛选；切换时自动保存，重启保留归属，修改当前文档归属不丢正文或图片。
2. 没有项目的系统任务可通过新增和快录创建，详情修改后仍无项目；已有项目任务不被系统关联改写项目。
3. 为两个系统及通用范围建立虚构资料，导出 A 只含 A 的完整台账、任务、有效文档与图片。
4. Markdown、DOCX、PDF 可独立打开阅读，每份文档有独立文件；中文、长表格、代码和图片通过实际渲染检查。
5. 用户选择导出密码时需要解锁，密码进入指定系统的总览，未选择的 Token／私钥不输出；取消和失败不留半成品、不泄漏到日志或普通快照。
6. 相同标题、非法文件名字符、缺失图片、无法写入等边界有明确行为；原应用资料与加密备份不被修改。
