# 更新文件清理与主动重启提示

日期：2026-10-20。对应[自更新规格](spec.md)用户故事 83–88。

## 本轮行为

- 下载、包校验完成后主动显示“立即重启并更新 / 稍后重启”。独立提示不包含长版本说明；稍后、关闭或 Esc 继续当前工作，品牌旁的更新按钮可再次打开。
- 每次下载准备有独立标识，重复状态不会反复提醒；相同版本重新下载后仍会再次提示。立即重启复用安装位置预检、保存、完整加密备份、安装助手和退出流程。
- 安装助手收到匹配版本的成功健康回执后，在仍持有安装锁时清理 `.previous`、`.previous-retired` 和本次私有下载目录中的 ZIP、解压应用。应用身份、所有权、占用和目录边界不合格时保留目标。
- 清理结果单独记录；成功清理后更新历史不再提供失效的旧应用定位入口。完整加密备份、用户资料及事务日志保留，清理受阻也不改写已完成的健康检查。

## 交付边界

实现验收时，这批源码尚未提交、推送或发布，没有替换 `/Applications` 中的现有应用。预览包使用当时的源码版本号 0.1.6，不能当作远端正式 v0.1.6 的重新发布资产。用户随后已授权“提交并发布”；正式版本使用新的版本号、远端已提交源码及发布流程验证结果，独立于上述预览验收。

清理适用于使用新安装助手发起且通过健康确认的更新。旧版助手、历史中断或人工恢复遗留的文件不会被扫描并追溯删除；健康未确认时也保留恢复材料。成功升级不再长期保存应用副本供本地降级，需要历史版本时通过 GitHub Release 获取，并自行确认资料兼容性。

未在本轮执行真实 GitHub 版本间升级、系统打开授权或 Windows 实机验证。未修改共享弹窗的拖拽区域；本轮按钮验证来自 Electron 自动化，不替代以前鼠标关闭问题的原生指针验收。
