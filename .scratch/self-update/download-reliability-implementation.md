# 更新下载恢复：实施与发布验收

状态：v0.1.18 已于 2026-10-29 正式发布；旧版自动升级在本机慢网下失败，见下方分阶段结论。日期：2026-10-29。

依据：[故障调查](v0.1.17-download-investigation.md)、[受控续传决策](../../docs/adr/0015-recover-release-downloads-with-verified-resume.md)、[两阶段验收决策](../../docs/adr/0016-verify-real-github-updates-after-publication.md)。

## 已实施

- 下载器对可恢复网络错误和临时服务错误最多尝试三次。每次私有资产请求重新经过固定 GitHub API 与可信重定向校验；授权只发给 API，不转发到 CDN。
- 同版本暂存包使用受限目录与不含凭据的身份记录，最多保留 24 小时。只有可核对的 `206/Content-Range` 才追加；`200` 回退全量下载，`416` 或不匹配范围拒绝拼接。完整 ZIP 再次通过 SHA-256 与应用包验证后才成为待安装状态。
- 连接连续两分钟无新字节与整个任务两小时上限分开处理；取消、版本变化、校验失败与成功安装分别按已确认规则清理。磁盘读写、授权和完整性错误不作为网络瞬断重试。
- 更新界面显示尝试次数、进度、取消与重试；可恢复网络失败提供正式 Release 的手动安装入口。本机历史记录脱敏阶段、已下载字节、尝试次数与错误码，取消单独标记。
- 更新功能和历史指引、待发布操作说明已跟随流程修订；修正真实安装验收脚本的独立备份密码前置，并新增当前源码的真实私有 GitHub 传输预检。
