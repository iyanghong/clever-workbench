# 账号列表的密码展示与快捷复制

Status: ready-for-human

2026-10-19：用户指出账号列表右侧两个相同复制图标难以区分，要求增加密码列、单项显隐、页面明文切换、字段旁复制和整行复制。使用 grill-with-docs 梳理交互，Q1–Q5 已全部确认，按原请求开始实现。

## 已明确的需求

- 账号列表新增独立密码列，默认以 `***` 遮罩，可展开为明文。
- 列表上方提供整页明文显示按钮。
- 鼠标经过用户名、密码时，在该字段右侧显示复制按钮，复制目标不再依赖辨认两个并列的相同图标。
- 每行最右侧为独立的“复制整行”操作，复制内容按名称、地址、用户名、密码换行组织。
- 操作保留现有秘密加密与按需解锁。页面遮罩与资料库中的秘密加密是不同概念；显示明文不改变存储形式。

示例仅使用虚构资料：

```text
Jenkins / 运维
https://jenkins.example.invalid
operator
example-password
```

## 设计树

- 列表呈现：密码独立列与单项复制（明确）→ 全部显示范围（Q1）→ 显示生命周期（Q3）。
- 整行复制：四行文本（明确）→ 遮罩时的复制行为（Q2）→ 多地址、无地址、非密码凭据规则（Q4–Q5 已确认）。
- 实施范围与验收：Q1–Q5 确认后按原请求进入实现。

## 用户已确认

1. Q1：采用“显示当前列表密码”仅覆盖当前筛选结果，切换系统、分类或筛选条件后恢复遮罩。
2. Q2：采用整行复制真实密码，锁定时先解锁；取消不改剪贴板。
3. Q3：采用明文保持到手动隐藏、离开页面或保险库锁定。
4. Q4：采用整行标题为“所属对象 / 账号用途”，入口取常用地址，资源取地址与端口，系统环境账号取系统登录地址；缺失字段保留空行。
5. Q5：采用密码列仅展示密码；无密码标明“未保存密码”，Token／私钥保留带文字说明的独立操作，整行密码位置留空。

以上五项已获用户确认。

## 改造前事实

- 改造前账号汇总列表末列同时放用户名和多种凭据的复制按钮，缺少独立密码列。
- 账号所属对象可为访问入口、资源或系统环境；入口已支持常用地址。
- 已有秘密详情的单项显隐、按需解锁与锁定清空能力可复用。
- 秘密复制由主进程完成；30 秒后及锁定时清理剪贴板。普通文本复制不具备该行为，含秘密的整行复制须复用敏感复制路径。
- 现有 ADR 0004 与本次展示需求不冲突；未涉及新的领域身份关系，暂不新增术语或 ADR。

## 验收

1. 初始密码列只含遮罩或“未保存密码”，未请求密码明文；用户名／密码复制操作位于对应字段右侧，鼠标悬停或键盘聚焦可见。
2. 单项与当前筛选结果批量显隐均按需解锁，取消不显示秘密；过滤、换系统、分类、离开、锁定或资料更新后清空明文，迟到的读取结果不重新出现。
3. 整行复制由主进程按账号 ID 读取当前资料，按名称／地址／用户名／密码拼接；不把 Token 或私钥放进密码字段，缺失项保留空行。
4. 整行含密码走敏感剪贴板路径，30 秒及锁定时清理，后续用户剪贴板内容不误删；取消解锁或复制失败不写入半份内容。
5. 宽窗口的账号列表打开详情时保留密码和整行复制入口；窄窗口允许表格横向滚动，不把用户名与密码复制混放。
6. 明文不进入列表本机偏好、日志或普通快照；验证使用虚构资料。
