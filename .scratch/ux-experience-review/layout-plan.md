# 共用框架与台账首版布局方案

Status: ready-for-agent

确认日期：2026-10-21。依据：[体验评审与 Q1–Q7 确认记录](review.md)。代码基线为 v0.1.7。

Completion: 设计讨论与方案整理完成；产品实现、界面验收、提交和发布尚未开始。

## 目标与范围

首轮改善共用框架与台账页面的视觉层级和空间分配，让用户更容易扫读列表、辨认当前对象并查看完整资料。接受重排工具区、精简重复层级和统一控件的中等幅度改版。

采用“列表紧凑、详情舒展”的密度。沿用现有 macOS 风格、中性背景、蓝色强调和轻度侧栏材质，统一标题、辅助信息、按钮、圆角及间距。

首轮包括应用共用框架、台账列表与详情、系统管理动作及全局快速新建的视觉分组。首页、任务和文档在首版效果确认后再推广同一规则；首轮修改共用样式时仍需保证这些页面可用。

创建、保存、复制、解锁、筛选、导出及资料恢复沿用既有业务路径。最初评审中的保存一致性、搜索匹配、跨页工作位置、后台通知等候选仍单独保留。

## 页面结构

### 共用框架

保留左侧导航和稳定的全局搜索／快速新建入口。内容区采用一致的水平对齐和层级：全局能力、当前系统与页面动作、分类与筛选、资料内容。

页面标题与工具区减少重复的视觉强调。通过字号、字重、留白和细分隔建立层次；正文、表格及编辑区域保持稳定对比度。窗口拖拽区与可交互控件明确分离。

### 台账浏览状态

未打开记录时呈现完整表格，方便横向比较多条资料。

- 系统切换、当前资料分类、列表搜索、环境／标签筛选及当前分类的新增动作保持清楚可见。
- 数量提示简洁呈现。选择控件可达，尚未勾选时不常驻一排禁用的批量动作。
- 勾选记录后显示选择数量和完整批量操作，并能清楚取消选择。
- 粘贴表格、复制等既有能力保留明确入口，主要与辅助操作在视觉上拉开主次。

### 台账详情状态

正常宽窗口打开记录后，左侧由完整表格切换为摘要列表，右侧显示更宽的详情。

```text
┌──────────┬────────────────────────────────────────────┐
│          │ 全局搜索                         快速新建 │
│          ├────────────────────────────────────────────┤
│ 侧栏导航 │ 当前系统                         更多操作 │
│          │ 资料分类 · 搜索 · 筛选 · 当前分类新增      │
│          ├──────────────┬─────────────────────────────┤
│          │ 对象摘要列表 │ 当前对象 · 复制 · 编辑       │
│          │ 名称与背景   │ 关键资料                     │
│          │ 关键地址     │ 账号与其他详细内容           │
│          │ 当前选择标记 │                             │
└──────────┴──────────────┴─────────────────────────────┘
```

该示意表达结构，不规定最终像素尺寸。

- 摘要至少保留对象名称、环境等必要背景与关键地址。不同类型按既有信息选择摘要，避免把所有对象压成难以辨认的一行。
- 账号的用户名和秘密复制保持直接可达，复用现有解锁与剪贴板保护。
- 当前选择除背景变化外具备清楚的结构提示，避免只靠微弱色差辨认。
- 详情承担完整信息和主要操作，保留浏览与编辑的区分、保存反馈及长内容滚动。
- 返回清单后恢复完整表格，保留当前分类、筛选和必要的位置；多列比较在此状态进行。
- 窄窗口以单栏详情呈现，提供明确的“返回清单”。根据内容可用宽度判断布局，避免沿用过宽表格把详情挤窄。

## 操作收纳

| 动作 | 确认后的入口 |
| --- | --- |
| 切换系统 | 常驻系统切换器 |
| 新增系统 | 系统切换器中的明确动作 |
| 系统信息、导出资料 | 系统区域的“更多”菜单 |
| 当前分类新增、搜索与筛选 | 当前列表工具区 |
| 复制对象、复制字段及账号信息 | 保留对象附近的直接操作 |
| 批量复制等选择操作 | 勾选后显示 |

系统管理与导出增加一次打开菜单的操作，这是本轮已接受的取舍。菜单需支持键盘、关闭、焦点返回和清楚的可访问名称；收纳后仍能辨认其作用范围是当前系统。

## 快速新建

9 个动作在同一弹窗中分成两组，组内直接点选：

| 分组 | 入口 |
| --- | --- |
| 工作记录 | 新任务、新文档 |
| 台账资料 | 新系统、新访问入口、新账号、新服务器、新资源、新环境、新服务 |

工作记录置于前方。采用组标题、适当组间距和紧凑行式布局建立主次，保留必要的说明。内容较长时允许在弹窗内滚动，标题、关闭控件和键盘焦点始终可达。

这两组是菜单的视觉组织方式，沿用原有领域对象、创建背景与创建后的业务行为。

## 验收标准

以下是实现后的必要验证，不代表已经完成。

1. 正常窗口中可扫描完整台账；打开对象后呈现摘要列表与宽详情，避免过宽的完整表格挤占右侧空间。使用多条演示数据验证，不能仅凭空列表判断空间利用。
2. 窄窗口可查看完整详情并返回清单；长名称、地址、备注及账号不会挤出主要操作，页面没有意外横向溢出。
3. 分类、搜索、环境／标签筛选、单条复制、账号复制、批量选择及当前分类新增继续可用。取消勾选后批量动作恢复到未选择状态。
4. “更多”可以打开正确系统的信息与导出；系统切换器可以切换和新建系统。菜单、弹窗关闭与焦点返回正确。
5. 新建分组包含全部 9 项，任务和文档居前；现有系统／环境背景传递、保存协调及错误提示保持有效。
6. 浅色、深色、跟随系统、高对比、减少透明度和减少动态效果均可用；文字及选中态清楚，键盘焦点可见。
7. 修改公共布局后检查首页、任务、文档、设置及更新弹窗，防止共用样式产生回归。涉及拖拽区域的鼠标点击按项目规范做实际原生验证。
8. 按项目要求完成生产构建及相关 Electron 回归，使用隔离资料目录，分别记录开发运行与打包运行结果。

## 实施入口与文档边界

应用框架主要位于 [App.tsx](../../src/App.tsx)、[全局搜索](../../src/features/search/GlobalSearch.tsx) 和 [styles.css](../../src/styles.css)；台账实际入口为 [LedgerWorkspace.tsx](../../src/features/ledger/LedgerWorkspace.tsx)，复制及选择能力位于 [LedgerCopy.tsx](../../src/features/ledger/LedgerCopy.tsx)。新建入口由 [QuickCreate.tsx](../../src/app/QuickCreate.tsx) 与 [模块登记](../../src/app/modules.tsx) 共同组织。

本轮选择属于可逆的界面组织调整，没有改变系统、环境、任务、文档或凭据的含义，继续使用 [CONTEXT](../../CONTEXT.md) 与已有 ADR，因此不新增重复术语表或架构决策。
