- [x] 多选标签默认匹配任一，支持切换匹配全部；清空标签条件恢复未限定标签的范围。
- [x] 与系统、完成状态及既有查询条件共同生效，先筛选再计算优先区、分组和数量。
- [x] 优先区不得绕过筛选带出其他系统、状态或标签范围的任务，空结果显示正常空态。
- [x] 标签改名、删除或任务标签变化后筛选结果及时更新；验证任一、全部、无命中和临期任务交叉场景。
