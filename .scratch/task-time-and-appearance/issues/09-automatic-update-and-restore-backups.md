# 09: 自动备份与更新、恢复前副本的独立保护

**What to build:** 自动备份、安装更新和恢复前保护统一使用独立备份密码，未配置时在首次需要的操作中完成配置。

前置任务：[08：旧资料升级与独立备份密码管理](08-legacy-upgrade-and-backup-password-management.md)。

- [x] 启动及普通工作不拦截；未设置过主密码的旧资料也走首次备份配置流程，自动备份状态明确显示未启用。
- [x] 首次启用备份或安装更新时配置独立备份密码，取消仅取消本次动作；更新不再要求先设置主密码。
- [x] 保留有变更时每日一次、最近 7 份及锁定秘密时也可运行的行为；自动和操作前副本均可跨设备恢复全部凭据。
- [x] 恢复前先成功保存当前资料副本：优先使用当前备份保护，未配置时使用本次导入包的恢复密码并说明用途。
- [x] 副本写入、预检、更新前备份或资料切换失败时停止破坏性后续步骤，保留原资料并允许重试；不能静默跳过保护。
- [x] 验证首次配置及取消、后台备份、重启跨日、更新前阻断和恢复回滚，不能把测试全部留到最终验收。
