- [x] 已有主密码资料升级后，以升级时的主密码作为初始独立备份密码；不改写历史备份，旧包各用生成时密码恢复。
- [x] 既有主密码更改不再联动备份密码；新备份的归档与内部凭据都能只凭独立备份密码恢复。
- [x] 设置页支持独立管理备份密码，修改只影响新包；本机资料仍可访问时允许重新建立今后的保护，不宣称可解开遗忘密码的旧包。
- [x] 旧格式预检、恢复以及升级后的新格式都验证秘密完整性，不把内外保护材料不一致当作可恢复。
- [x] 迁移或密码变更失败保留原资料和有效保护；用旧库、多个历史密码及新旧包往返验证升级连续性。
