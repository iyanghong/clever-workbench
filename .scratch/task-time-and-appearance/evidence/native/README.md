# Mac 原生鼠标验收

2026-10-20 用户手动解锁 Mac 后，使用 CUA 原生桌面接口完成补验。验收对象为提交 `7c42405` 对应的打包应用，窗口标题“CWB 临时验收窗口”，内容尺寸为 1100 × 760 逻辑像素，截图为 Retina 2200 × 1520 像素。

应用位于 `/tmp/clever-workbench-native-final-20261020/mac-arm64/Clever Workbench.app`。启动时指定独立临时 `CLEVER_WORKBENCH_DATA_DIR`，只包含人工构造的测试系统、任务与标签。实际安装版及用户资料未参与操作，验收后已退出测试进程并清理该临时资料目录。

| 操作 | 观察结果 |
| --- | --- |
| 原生坐标点击工具栏“快速新建” | 弹窗正常打开，没有被工具栏拖拽区域拦截 |
| 原生坐标点击关闭按钮 | 弹窗关闭，AX 状态确认焦点返回“快速新建” |
| 返回焦点后按 Return，再按 Esc | 能重新打开并关闭弹窗，焦点再次返回原入口 |
| 切换紧凑任务列表并打开详情 | 临期文字、图标和颜色标签仍可见，详情时间控件可达 |
| 原生坐标点击任务详情关闭按钮 | 详情正常退出并显示任务列表 |
| 原生坐标点击台账工具栏“系统信息” | 表单正常打开；关闭后焦点返回“系统信息” |
| 粘贴中文系统说明，关闭并重新打开 | 说明完整保留，显示已保存 |
| 粘贴 20 行虚构服务器资料并滚动长表单 | 标题和关闭按钮仍留在视口内 |

本轮关键工具栏和关闭动作采用原生坐标鼠标输入，没有以 DOM 的 `click()` 或页面脚本触发代替。键盘与滚动同样使用 CUA 原生接口。测试启动及样本建立由隔离的 Electron 测试程序完成。
