## 发布渠道

复用仓库现有版本准备和 GitHub Actions 发布流程，生成 macOS Apple Silicon ZIP、DMG、SHA256SUMS；云端再执行完整单元测试、真实安装包校验和安装版桌面测试，验证通过后才公开 Release。

本机 Git HTTPS 凭据助手未提供登录，但 `gh` 已有具有仓库和工作流权限的登录；发布调用复用该登录与现有发布库，不输出凭据，不修改 Git 署名。SSH 完整克隆预览超时，HTTPS 隔离克隆预览成功；原仓库的 SSH `origin` 保持不变。

本文记录发布前检查，不将随后尚未执行的云端打包、正式发布或真实网络更新安装标为通过。最终构建源码、版本提交与验证结果以 Release 说明及其链接的 Actions 记录为准。未验证 Windows 实机，也未安装或替换本机正式应用。
