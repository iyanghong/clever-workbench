# 台账资料快捷复制

Status: ready-for-human

2026-10-19：用户希望将账号页快速复制延伸到其他台账，重点场景是将服务信息、服务器配置复制给别人。采用 grill-with-docs 梳理方案，用户已在 Q10 确认理解一致并开始实现。

## 已确认

1. Q1：只输出纯文本，适合粘贴到聊天、邮件等位置；不增加 Markdown 复制模式。
2. Q2：默认“复制资料”只带配置，账号按需选择；已确认的账号页整行复制行为不变。
3. Q3：支持列表多选，每个对象单独成段；不默认选中整个系统。
4. Q4：覆盖服务器、应用／服务与部署节点、数据库／中间件、访问入口、运行维护；任务和文档保持原有编辑与导出能力。

## 界面建议（已确认）

- 字段右侧：悬停或键盘聚焦时出现单值复制，提示明确说明复制 IP、仓库地址等。
- 列表每行与详情头部：提供有文字的“复制资料”，直接得到默认摘要。
- 旁边的更多选项：需要时选择“包含账号…”，日常复制不先弹表单；范围沿用当前环境筛选。
- 列表多选：显示所选数量与“复制所选资料”，按当前列表顺序、对象间空行分隔。
- 只复制到本机剪贴板，不直接向他人发送。

## 纯文本示例（虚构）

```text
服务器：应用节点 01
所属系统：协作平台
适用环境：生产
IP：192.0.2.11
操作系统：Kylin Linux V10
CPU：16 核
内存：32 GB
硬盘：500 GB
用途：运行订单服务
```

## 设计树

- 输出载体 → 纯文本（已定）→ 对象模板、空字段与范围说明。
- 复制内容 → 默认配置、账号按需（已定）→ 服务部署范围、关联服务器字段、账号来源及密码选择。
- 选择对象 → 单条与多选（已定）→ 筛选变化、去重与批量顺序。
- 对象范围 → 台账六类（已定）→ 入口地址、部署节点与运维文档摘要的深度。
- 交付 → 完整交互与验收确认后，由用户决定保留文档或开始实现。

## 既有边界

- 系统、服务、服务器与部署节点已有明确领域含义，沿用现有术语。
- ADR 0004 的按需解锁与锁定清理继续有效；含秘密的组合复制需使用敏感剪贴板路径。
- ADR 0006 的系统资料包用于整套文件导出，本轮对象资料复制作为日常沟通入口。
- 不把原始资料文件或真实凭据写入方案与测试。

## 事实核查

- 非账号列表缺少整条资料复制；入口行侧重打开网站，资源行侧重进入账号。
- 服务器已有操作系统、CPU、内存、硬盘、用途及自定义字段，配置详情可直接作为摘要来源。
- 服务包含公共信息及按环境区分的多个部署节点；服务不直接拥有账号，关联服务器的账号不能自动认定为应用账号。
- 运行维护可关联服务／资源和步骤文档；文档不具备精确的服务归属，不能把系统全部文档自动附入服务摘要。
- 系统导出已有各类型的字段组织、环境／对象名称解析，可复用这些规则，但对象复制需单独限定范围。
- 当前“复制资源／入口／账号”指创建新对象，与剪贴板复制不同；新入口统一使用“复制资料”。

## 第二轮已确认

5. Q5：采用服务公共信息加当前筛选环境的节点；全部环境时分组列出全部节点，仅系统通用时只复制公共信息。
6. Q6：采用当前对象资料完整，关联资料仅简要引用；不自动展开服务器配置或文档全文。
7. Q7：采用访问入口复制全部具名地址并标常用；账号页整行复制仍采用常用地址。

上述三项已由用户确认。

## 第三轮已确认

8. Q8：采用服务器、数据库和入口列出自身账号；服务／节点列出本次复制范围内关联服务器的账号；运维记录列出其关联资源或服务部署服务器的账号。候选均标注来源、默认不勾选；不将服务器账号认定为应用账号。
9. Q9：采用选中账号后默认附带用途和用户名，另勾“包含密码”才解锁复制；Token／私钥继续通过已有独立操作复制。

上述两项已由用户确认。

## 对象摘要模板（已确认）

共同背景包含对象类型、名称、所属系统、实际适用环境和标签。以资料本身的适用范围为准，不因页面筛选为“生产”就将系统通用对象改称“生产专用”。

| 对象 | 默认复制内容 |
| --- | --- |
| 服务器 | IP、端口、操作系统、CPU、内存、硬盘、用途、其他已填写字段和说明 |
| 数据库／中间件 | 地址、端口、类型、版本、实例、库名、主备信息、其他已填写字段和说明 |
| 服务 | 名称、仓库、状态及状态说明、备注；再按 Q5 附部署节点 |
| 部署节点 | 服务、环境、节点名称、固定／按需模式、规模、有效地址、端口、关联服务器名称及备注；地址继承服务器时注明来源 |
| 访问入口 | 全部具名地址及常用标记、说明；账号仅在明确选择后附带 |
| 运行维护 | 作业／备份类型、频率、状态、说明、关联对象名称及步骤文档标题；不自动拼接文档正文 |

## 默认操作规则（已确认）

- 不新建模板编辑器；每类对象采用一份固定文本模板。空的普通字段省略，多行备注保持原有换行；不复制内部 ID、保存时间等实现信息。
- 单字段复制仅复制值，整份资料使用“字段名：值”，每个对象独立成段。
- 多选限当前系统、分类和筛选结果，支持“选择当前结果”；切换系统、分类、环境、标签、运维类型／状态或搜索条件后清空选择。
- 同一对象按身份去重，顺序沿用当前列表；独立对象即使同名同地址也不合并。服务携带的部署节点不因其他范围而重复。
- “包含账号…”显示摘要范围、候选账号来源和所选数量。选项仅本次生效，下一次恢复不带账号、不带密码。
- 多对象的附带账号集中放在末尾，按所属对象分组，同一账号只出现一次。未关联服务器的节点不推断账号来源。
- 服务账号候选只来自本次包含的部署节点关联服务器；仅复制服务公共信息时不引入其他环境的服务器账号。单独复制节点时只考虑该节点的关联服务器。
- 运维记录若指定环境，其关联服务的服务器账号候选限该环境；未指定环境时沿用当前筛选范围。关联资源时仅列该资源自身账号，不遍历整个系统。
- “包含密码”默认不勾选，只作用于本次勾选的账号；未保存密码的账号注明“未保存密码”，不替换为 Token／私钥。未选中账号时不会复制任何秘密。
- 复制前保存当前编辑，读取最新资料；保存或读取失败、取消解锁时不覆盖剪贴板，保留当前输入与选择。
- 含密码的输出由主进程读取并组装，沿用 30 秒及锁定清理，只清理仍属于本次复制的剪贴板内容。普通配置不触发解锁。
- 复制成功提供明确反馈；记录已被删除或引用失效时说明无法复制，不静默输出不完整的旧资料。

## 验收

1. 服务器一键复制包含已填写的软硬件配置、用途及自定义字段，无需进入编辑。
2. 复制服务按当前环境选择正确节点；全部环境明确分组，仅系统通用只带公共资料。
3. 节点缺独立地址时正确取关联服务器地址并注明来源；不自动附服务器硬件或账号。
4. 访问入口保留所有具名地址及常用标记，账号页整行复制规则保持不变。
5. 运维摘要含关联对象及文档标题，无文档全文或无关系统文档。
6. 多选结果按当前列表顺序输出、同身份去重；切换筛选不留隐形选中项。
7. 账号候选遵循 Q8，默认不勾选；勾选后默认只有用途和用户名，另勾“包含密码”才解锁读取；账号标明来源，同身份去重，无密码时不混入其他凭据。
8. 修改后立即复制能得到新值；保存失败、取消解锁和读取失败不改剪贴板。
9. 含密码的复制支持锁定撤销与计时清理，后续用户复制内容不被误删。
10. 字段复制、列表复制、详情复制与批量复制使用一致的字段名与格式，可用键盘访问。
