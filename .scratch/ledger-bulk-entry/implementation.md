# 台账批量录入实施记录

2026-10-22。按[已确认规格](spec.md)实施，功能与相关验证已完成。

## 用户可见变化

- 台账分类栏的“粘贴表格”改为“批量录入”，默认带入当前分类与环境；覆盖原有全部 10 类对象。
- 可直接填写多行、增加和删除行、取消勾选；已有批量字段均可编辑，资源可添加附加字段。空白行不提交，部分填写但缺名称的行给出提示。
- Word／Excel 表格与 TSV 继续使用原有解析和映射；映射后追加到编辑表格，保留原先的手填和修改。追加前提供遮蔽密码的预览，重复表头、错位与未知列继续要求校对。
- 横向滚动时固定名称列，表格在窄窗口中独立滚动；复用主题、对话框、焦点返回及减少动态效果等既有能力。
- 一批固定系统、类型与环境；账号按所属对象查重和继承范围，部署节点使用服务与环境。服务批量新增现在会在同一事务中保存所选环境。
- 未提交批次接入保存协调。关闭、Esc 与原生退出不会静默提交或丢弃；在途提交等待完成。失败保留输入，成功清理临时内容。草稿不写入持久化存储。

实现复用 `captureLedgerBatch`、现有字段和秘密接口、事务与批次幂等机制，没有新增依赖、数据库表或 IPC 方法。[使用说明](../../docs/usage.md)已同步。

## 交付范围与限制

验证为本机 macOS 上运行生产构建的开发 Electron，未构建安装包、安装本机应用、验证 Windows 实机或执行真实自动更新安装。已验证更新所复用的保存协调接口，不将其表述为完成一次真实更新。

没有运行整仓库全量测试，也没有创建提交、推送或发布。文件导入、跨系统混合录入、多环境和标签批量配置、持久化录入草稿按已确认范围不实现。

工作区另有系统导出与系统凭据保护的并行改动，均保留。`electron/vault.ts` 和 `docs/usage.md` 的本次修改仅涉及批量服务范围和批量录入说明；不将这些文件中其他改动计入本功能。
