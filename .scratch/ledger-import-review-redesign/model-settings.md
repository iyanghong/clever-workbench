# 分析模型配置设计讨论

Status: ready-for-human

用户希望从软件中快速安装 Ollama、选择要下载和使用的模型，并能配置第三方模型服务。本轮先确定页面交互与资料边界。

## 已确认的设计

- **文件外发范围（Q8）**。内部敏感文件始终在本机分析。用户明确标记为可外发的文件，可以交给所选远端服务提取候选。已有台账留在本机比对。配置好服务或通过试连，仅表示服务可用。
- **Mac 安装（Q9）**。工作台下载并校验官方安装包，打开官方安装界面。用户完成系统安装或授权后，工作台自动检测 Ollama 并接续到模型选择；已安装的机器直接选择模型。
- **模型选择（Q10）**。提供推荐列表，也允许输入自定义本地模型名称与标签。下载完成后先用虚构资料验证本机推理与台账结构化输出，验证通过再供导入选用。
- **第三方协议（Q11）**。首版使用 OpenAI 兼容的 Chat Completions 接口，可填写接口地址、模型名和可选 API Key。连接测试和虚构台账提取分别展示结果。
- **仅配置第三方（Q12）**。允许外发的文件可在未安装 Ollama 的设备上完成全部导入。指定远端提取候选；工作台在本机按名称与地址寻找相似对象，计算用户选定目标的字段差异。用户可手动指定更新目标并逐行核对，最终统一保存。本机模型就绪时可补充语义相似或迁移建议。

## 建议的入口

在「设置 → 分析模型」管理连接。导入页显示本次使用的服务、模型、处理位置和就绪状态。从导入页进入设置时，返回后保留已选文件及系统，仍由用户点击开始分析。

| 页面 | 主要操作 |
| --- | --- |
| 本机 Ollama | 检测安装状态；缺少运行时就引导安装，装好后自动检测。已安装时列出工作台可用的模型，支持下载、查看进度、取消和选用。 |
| 第三方服务 | 填写服务名称、接口地址、模型名和可选 API Key。正式实现应通过专门的加密存储保护密钥。原型使用示例凭据，以虚构样例分别演示测试连接和测试台账提取。 |

## 与当前实现的差异

现有导入页能启动已安装的 Ollama，在工作台管理的模型目录下载并校验 Qwen3 4B 和 8B。缺少运行时时链接官网。运行时、已下载模型、适用于台账提取的模型，应分别显示各自状态。

一般文件提取可能使用系统名、段落或单元格内容及来源位置；查重还可能使用当前系统已有台账的名称、环境、地址和字段差异。文件允许外发与已有台账允许外发是两项独立决定。试连只使用虚构系统、文件和已有记录。当前资料处理继续遵循 [ADR 0017](../../docs/adr/0017-reviewed-local-model-imports-without-source-retention.md)。

## 体验原型

打开[分析模型配置原型](prototype.html#models)。初始示例设备没有 Ollama。测试并保存第三方服务，返回文件导入，显式标记示例文件允许外发，选中该服务后开始提取。校对页显示“本机规则比对”，仍可对照已有台账、勾选更新字段并完成模拟保存。若改选“本机 Ollama”，可体验安装接续、推荐或自定义模型下载、取消、验证和选用。

建议导入页默认选中“仅本机”。用户选定可外发文件和具体服务后，主按钮显示“使用〈服务名〉提取此文件”。远端请求只使用该文件中提取所需的片段，明确识别的秘密值在本机替换成引用；当前系统名称、环境清单、已有台账和旧字段值都不作为远端提示词上下文。更换文件或目的服务后重新选择。此处仅为页面和请求边界设计。

官方依据见 [Ollama 的 Mac 安装流程](https://docs.ollama.com/macos)、[已安装模型列表](https://docs.ollama.com/api/tags) 和 [结构化输出](https://docs.ollama.com/capabilities/structured-outputs)。
