# Clever Workbench · Ant Design 6 全页面 Demo

独立的浏览器交互演示，使用真实 `antd@6.7.0`、React 19 和 Phosphor 图标。目的是评估组件库替换后的完整软件外观和操作方式，正式 Electron 界面的接入进展见[迁移记录](../antd6-ui-migration/implementation.md)。

从仓库根目录启动：

```sh
npm run demo:antd
```

打开 [本地预览](http://127.0.0.1:5186/)。首次在新工作区使用时，先执行 `npm --prefix .scratch/antd6-workbench-demo install`。本目录独立管理演示依赖。

执行 `npm run demo:antd:build` 可进行类型检查、生产构建，并生成 `Clever-Workbench-AntD6-Demo.html`。这个单文件打包了脚本、样式和图标，可以直接双击打开，无需开发服务器或网络。

## 数据与边界

所有系统、地址、任务、文档和凭据均为虚构示例。台账、任务、文档、收藏和外观的修改保存在页面内存，切换模块继续保留，刷新重置；部分设置与原生流程仅演示当前页面状态。浏览器演示不会连接正式应用的 `window.desktop`、SQLite、系统钥匙串或用户资料目录。

ZIP、凭据加密、加密备份、恢复和应用更新展示流程及状态，不执行真实原生操作。可下载的备份资料是明确标注的**未加密 JSON 演示快照**，不能用于正式应用恢复。文档编辑器使用 Markdown 输入与安全的 React 阅读渲染，没有复刻正式应用完整的 Vditor／Tiptap 富文本能力。

## 验证

启动预览后，从仓库根目录执行：

```sh
node .scratch/antd6-workbench-demo/verify.mjs
```

验证脚本复用仓库已安装的 Playwright。优先使用已安装的 Playwright Chromium，否则使用本机 Chrome；可通过 `DEMO_BROWSER` 指定可执行文件，通过 `DEMO_URL` 指定预览地址。

脚本检查 28 个页面在 1440 × 960 浅色／深色及 820 × 650 窄窗口下的显示与页面横向溢出，保存代表页面截图，并检查台账、任务、文档、搜索、工具、备份与更新的主要交互。结果见 [验证记录](evidence/verification.json)。浏览器验证不代表 Electron 原生拖拽区、安装包路径或 Windows 实机验证。

主要入口：`src/App.tsx`。页面按 `Ledger.tsx`、`Tasks.tsx`、`Documents.tsx`、`Tools.tsx`、`Review.tsx`、`Settings.tsx` 和 `Maintenance.tsx` 划分；演示数据位于 `src/data.ts`。
