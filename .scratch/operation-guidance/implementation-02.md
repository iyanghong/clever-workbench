## 交付行为

- 设置中可查阅当前及随包历史版本摘要，并按当前有效功能打开用法；已移除功能、缺失当前说明和历史范围均如实说明。
- 当前运行版本可以展示本包 pending 绑定，历史仅接纳 published 记录；首次只考虑当前版本，后续升级按范围合并，同功能一个入口、不同变化保留。目标本身 none 不会掩盖中间变化，失败标签不混入历史。
- 自动提示等待页面资料就绪、输入及中文组合结束、保存成功、DOM 弹窗与主进程操作空闲；异步返回后再次检查。共享 Dialog 将指引及更新重启提示作为独占窗口协调，普通业务弹窗仍可嵌套。
- 实际 `showModal()` 成功且存在可见布局才确认已提示。排队、显示失败和退出等待不消费；关闭、重启、降级后再升级和手动重看不重置去重记录。
- 主进程通过受控 IPC 保存 userData 下独立设备记录，临时写入同步后原子替换；业务备份不包含它。恢复旧备份不回退记录，换设备仍按首次规则。
- 损坏记录只考虑当前版本；写入失败返回 `persisted: false` 并明确显示重启后可能再次提示，同一进程不反复抢焦点。正常关闭等待已开始的记录写入完成；关闭过程开始后不消费新的显示确认。
- 构建以原始文本复制全量 JSON 到包内供版本解释，不让坏 JSON 变成构建门槛，不重复复制图片。补充“重看版本操作说明”的真实帮助正文与实现契约。
