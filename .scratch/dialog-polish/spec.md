# 台账弹窗整理与关闭入口

Status: ready-for-human

用户反馈系统信息、粘贴表格、新增运维记录界面混乱，部分弹窗缺少关闭入口，要求直接优化。

## 范围与验收

- 共享弹窗统一标题栏、可见关闭按钮；长内容滚动时仍可关闭，保留 Escape、焦点恢复及原有保存／忙碌／退出保护。
- 系统信息按基本信息、环境管理、项目档案分区，字段有一致的高度、间距和标签；切换分区不丢输入。自动保存失败时不关闭、不丢输入。
- 粘贴表格有清晰的类型／环境设置、完整宽度的粘贴区、预览及底部操作区；关闭未提交内容仍需选择继续或放弃。
- 新增运维记录同时提供关闭和取消，不改变名称即可录入的业务规则。
- 验证正常与窄窗口、浅色与深色外观；不更改台账数据结构、秘密处理或导出规则。

## 实施记录

基线：6113a5170a450dbf1157d659d0e80fe019ef5820。

原回归 `npm run test:e2e -- tests/e2e/dialog-polish.spec.ts` 失败：系统信息内不存在“关闭系统信息”按钮。检查确认共享 Dialog 只渲染标题与正文；控件样式未覆盖嵌套的 select/textarea；系统与环境、项目管理堆叠。

实现统一关闭栏、表单控件与底部动作样式；系统分区保持挂载以保留编辑状态；任务确认框也复用共享 Dialog，图片预览保留已有关闭按钮。测试仅用虚构资料及独立临时资料库。


## 验证结果

- `npm run build`（含类型检查）通过。
- `npm test`：21 个文件、83 项测试通过。
- `npm run test:e2e`：41 项桌面测试通过。审查后补充长预览退出用例，先复现确认按钮处于视口之外，再修复为滚动并聚焦确认；最终针对性 3 项测试通过。
- 检查了浅色、深色、880×620 窗口、长内容滚动及关闭按钮可点击性；保存失败保留输入、Escape 焦点恢复、未提交粘贴的退出保护均通过。
- 当前仅为源代码修复，未替换已发布的 v0.1.0 安装包；Windows 11 实机未验证。
