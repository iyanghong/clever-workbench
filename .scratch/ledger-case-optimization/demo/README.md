# 台账与工作任务 HTML Demo

双击 `workbench-demo.html`，使用 Chrome、Edge 或 Safari 打开。所有脚本和图标均包含在单个 HTML 内，不需要安装依赖或启动服务。

`tasks-demo.fragment.html` 是任务部分的组装源片段；单独打开时自动跳转到同目录的完整 Demo，避免缺少台账容器时报错。分享或移动 Demo 时只需使用 `workbench-demo.html`。

默认进入工作任务页，可从左侧切换到台账。

- 正常布局：任务标题与系统、日期分行显示。
- 紧凑布局：每个任务固定为一行；长标题单行省略，点击标题可查看全文。
- 两种布局共用状态、系统筛选、搜索及快速完成操作；任务只可选关联系统。
- 可体验新增、完成、重开、详情修改，以及台账查询和详情。

仅使用虚构资料。任务和台账的示例修改只在本次打开期间保留，刷新重置；浏览器仅记忆任务布局偏好。复制秘密、打开外部入口和导出为操作示意，不连接真实资料库。未改动桌面应用的业务代码。
