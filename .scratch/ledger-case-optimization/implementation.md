Status: ready-for-human

用户于 2026-10-19 明确授权按 Demo 实施全部已确认优化，并补充任务可修改开始时间。原“先保留文档”的范围限制已解除。

## 实施顺序

1. 任务系统归属、旧背景迁移、开始时间、正常／紧凑布局，以及首页、搜索、回顾的一致性。
2. 台账多环境范围与标签、数据库资料、部署节点、运维清单；保护引用并兼容旧数据。
3. 按 Demo 重组台账工作区，默认只读、按需编辑、顶部系统切换和分类直达。
4. 表格粘贴、映射校对及原子新增，秘密继续经保险库加密。
5. 搜索、系统导出、备份与恢复覆盖新增对象；验证旧 v7/v8 数据迁移。
6. 类型检查、针对性测试、完整回归、代码审查和提交。

## 验收补充

任务开始时间可在新建与详情修改，不改变创建时间；按分钟保存，不得晚于当前时间或已有完成时间。失败保留输入，工作回顾按保存后的开始时间重算跨度。

使用隔离的虚构资料进行验证；`docs/资料/` 中原始资料不导入、不提交。Windows 11 实机仍不可用，沿用已有平台验证边界。
