# 领域文档

工程技能按以下约定读取本仓库的领域文档。

## 开始分析前

- 如果根目录有 `CONTEXT.md`，先阅读它。
- 阅读 `docs/adr/` 下与当前工作相关的架构决策记录。

文件不存在时直接继续。领域术语或决策明确后，由 `/domain-modeling` 按需创建。

## 文件布局

本仓库采用单一领域上下文：根目录的 `CONTEXT.md` 记录术语，`docs/adr/` 存放决策记录。

## 使用词汇表中的术语

在问题、方案、假设和测试中命名领域概念时，使用 `CONTEXT.md` 定义的术语。若缺少所需概念，先检查用词是否准确；确有缺口时，留待 `/domain-modeling` 补充。

## 指出与决策记录的冲突

如果当前方案与已有架构决策记录冲突，明确指出冲突。
