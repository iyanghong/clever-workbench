# 安装与资料保护

Clever Workbench 供个人离线使用，不需要注册账号。Mac 使用 Apple Silicon 安装包；Windows 使用 x64 安装程序。安装包、校验值和已验证环境以[交付验证记录](../.scratch/desktop-workbench/release-verification.md)为准。

## 安装和更新

Mac 打开 DMG，将 Clever Workbench 拖入“应用程序”；Windows 运行安装程序并选择安装位置。Mac 包使用本机 ad-hoc 签名保证资源完整性，没有 Developer ID 签名和公证；Windows 包没有发布者签名，操作系统可能要求确认来源。仅在确认安装包来自自己的项目后按系统提示打开，不需要关闭系统的整体安全保护。

更新前先导出完整备份，退出正在运行的应用，再替换程序。资料与程序分别存放，更新应用不会要求重建台账。旧 Clever Plan 使用独立身份和资料位置。

## 台账中的访问入口与服务器

在台账中选择系统后，可切换“访问入口”“服务器”和“环境台账”。访问入口和服务器都可以先作为系统通用记录，不必先建环境；筛选某个环境时会同时显示通用记录。

访问入口用于 Jenkins、GitLab 等工具。新增时名称必填，地址、首个账号和密码可以同屏填写，也可以留空。详情支持多个具名地址和多组角色账号；用星标选择常用地址、下拉框选择常用账号，再把入口设为常用，即可从工作台直接打开网站或复制账号。秘密仍按需解锁，所有地址共用该入口下的账号。

服务器可以记录名称、IP、用途、操作系统、CPU、内存、硬盘、端口和多组账号。新增弹层中展开“操作系统与硬件配置”即可一起录入，详情支持后续编辑；CPU 可直接写型号与核数，内存、硬盘可写“32G”“500G”。没有登录权限时只记机器资料即可。

入口和服务器可复制到另一个系统，副本独立维护。默认复制普通资料和账号元数据，勾选复制秘密后才要求解锁。服务器已有任务、文档或草稿引用时，先处理引用或复制为新记录，再调整环境，已有工作不会被自动改写。

新增台账、服务器配置、地址顺序、常用选择、收藏和秘密都包含在完整备份中。旧版台账及备份会在升级时保留原记录和关联。

## 文档与任务归属

文档页的“归属”可筛选全部、通用文档或某个系统。新建文档继承当前范围，详情中可随时修改系统；清除系统关联即为通用文档。项目独立选择，系统改变后，已有文档和任务的项目不会被自动改写。

新增任务和任务详情直接显示系统与项目选择。项目可以留空，也可以先只记标题，之后再补充归属。

## 导出系统资料

在台账中选择系统，点击“导出系统资料”。可同时选择 Markdown、Word（DOCX）和 PDF，保存为一个 ZIP 包。每种格式都有系统总览，每份关联文档和任务另存独立文件，图片随包保存或嵌入文件。总览包含系统基本信息、项目历史、环境、服务部署、服务器配置、访问地址和账号。通用文档、其他系统资料及回收站不包含在内。

默认包含账号密码，导出前按需解锁；Token 和私钥须另行勾选。所选秘密会以明文写入文件，交接前应确认接收对象和保存位置。取消解锁或保存不会生成文件，导出失败会清理本次临时输出。

系统资料包用于直接阅读和交接，不提供导入；换机恢复使用下方的完整加密备份。

外部图片会导出为说明文字，需显示图片时先在应用中导入。若源码包含原始 HTML，Markdown 导出会提示先将它放入代码块或选择 Word／PDF，避免正文结构被静默改变。

## 主密码

在首次保存秘密或导出备份时设置主密码，至少 6 个字符。密码、Token 和私钥单独加密；系统名称、地址、账号名、任务、文档和图片不需要解锁。写进普通备注或正文的敏感内容不会自动转为加密秘密，应放进账号的秘密字段。

重启后第一次查看或复制秘密时输入主密码，连续使用时不必重复输入。应用闲置 15 分钟、系统锁屏、休眠、退出或主动锁定会撤销会话。复制秘密后 30 秒清理仍由应用持有的剪贴板内容；后来复制的其他文字会保留。

在“设置 → 更改主密码”输入当前密码、新密码并确认。成功后秘密重新锁定；当前资料和之后的备份使用新密码，已有备份仍使用生成时的密码。更改不会改写历史备份。主密码丢失且没有可解锁副本时，秘密无法找回。

## 完整备份与换机

“设置 → 导出完整备份”生成 `.cwb` 文件。项目历史、台账、账号、任务、文档、必要偏好、草稿、回收站记录和引用图片整体加密。秘密锁定时仍可导出，无需先解锁。未设置主密码时不会生成未加密的替代备份。

自动备份默认启用，在应用运行期间检查。有变更时每日成功备份一次，保留本设备最近 7 份自动备份。手动导出、恢复前副本和其他文件不会纳入这项清理。可在设置里更改目录、查看成功时间或失败原因，并点击“立即备份”重试。应用关闭后不运行备份服务；建议把重要的手动备份另存到独立存储设备。

换机恢复步骤：

1. 将完整 `.cwb` 文件复制到目标电脑，打开“设置 → 从备份恢复”。
2. 选择文件，输入生成这份备份时的主密码。预检会验证认证信息、资料结构、附件和记录数量。
3. 查看摘要并确认整份替换。取消预检或密码错误不会修改当前资料。
4. 成功后回到工作台，秘密保持锁定；查看秘密时使用该份备份对应的主密码。

恢复会替换当前资料、草稿和回收站；替换前先生成当前资料的加密副本。原资料已经有主密码时，恢复前副本使用原主密码；新设备尚未设置主密码时，副本使用本次导入备份的密码保护。恢复前副本保存在本机资料目录的 `data/recovery/`，可以通过相同入口重新恢复。

备份不依赖原电脑 Keychain 或 DPAPI。恢复保留目标电脑的备份目录，清除原来的自动备份成功状态；资料和可访问性偏好来自导入包。旧包恢复后，可以再次更改主密码并生成新备份。

## 保存或恢复失败

保存失败时页面会保留编辑内容并显示错误，离开或退出会被阻止，直到保存成功。先按提示检查磁盘空间和目录权限，再重试；不要通过强制结束应用来代替保存。

备份目录不可用时，原有副本保持不变。更改目录或修复访问权限后重试，失败不会计为当天已经成功备份。

预检失败不替换资料。恢复前副本无法完成时，也不会切换资料库。遇到数据异常时先保留整个本机资料目录和已有备份，再根据错误信息处理，避免手动混合两份数据库与附件。
