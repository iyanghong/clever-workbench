# 安装与资料保护

Clever Workbench 供个人离线使用，不需要注册账号。Mac 使用 Apple Silicon 安装包；Windows 使用 x64 安装程序。安装包、校验值和已验证环境以[交付验证记录](../.scratch/desktop-workbench/release-verification.md)为准。

## 安装和更新

应用更新固定读取 `iyanghong/clever-workbench`。该仓库保持私有时，会使用当前电脑 Git 凭据助手保存的 GitHub HTTPS 登录；账号须有仓库读取权限。若更新提示无法访问，先确认本机 Git 能以已保存的登录访问该仓库，再点击“检查更新”。浏览器登录不会自动共享给 Git；应用不会把访问令牌写入安装包或更新历史。

Mac 打开 DMG，将 Clever Workbench 拖入“应用程序”；Windows 运行安装程序并选择安装位置。Mac 包使用本机 ad-hoc 签名保证资源完整性，没有 Developer ID 签名和公证；Windows 包没有发布者签名，操作系统可能要求确认来源。仅在确认安装包来自自己的项目后按系统提示打开，不需要关闭系统的整体安全保护。

macOS Apple Silicon 安装版可在“设置 → 关于”查看当前版本并手动检查固定 GitHub 仓库 `iyanghong/clever-workbench` 的正式 Release。应用启动及每 30 分钟自动检查一次；只有发现新版本时，侧栏顶部“个人工作台”右侧才显示“更新”按钮。下载中和等待安装时保留该按钮，可随时返回更新进度。点击“下载更新”，完成校验后在弹出的提示中选择“立即重启并更新”或“稍后重启”；选择稍后时可从更新按钮重新打开提示。立即安装前，程序先保存资料并创建完整加密备份，再由助手原位替换当前应用并重新启动。首次安装更新前会提示设置独立备份密码；取消配置或保存、备份、安装位置检查失败时停止本次更新。开发模式、Windows 及 Intel Mac 暂不支持此流程。

在“设置 → 关于”或版本面板可查看最近 30 次更新记录、阶段耗时，并定位备份、旧应用与日志。只有新版本、资料库、窗口及通信均确认成功才显示更新成功；遇到权限或系统安全拦截时按系统提示处理，不需要关闭 Gatekeeper。更新不会自动覆盖数据库或将迁移后的数据交给旧版本；需要恢复时先保留当前资料，再明确选择兼容的旧版本和完整备份。安装包仍可通过“历史版本”手动下载。

资料与程序分别存放，更新应用不会要求重建台账。旧 Clever Plan 使用独立身份和资料位置。

## 快速新建

顶部的搜索和“新建”在各页面保持同一位置。“新建”弹窗直接列出两组动作：“工作记录”包含新任务、新文档；“台账资料”包含新系统、新访问入口、新账号、新服务器、新资源、新环境、新服务。选择后进入对应录入页面，沿用当前已确认且适用的系统、环境或资源背景；仍可在表单中调整。窄窗口中可滚动查看全部动作。台账新增字段按需填写，常用信息直接显示，配置和运维资料折叠展开；关闭有未提交内容的表单时，可继续填写或明确放弃。提交期间暂停编辑，失败保留输入。关闭后焦点回到“新建”。

## 台账浏览与系统操作

点击台账顶部的当前系统名称打开系统选择器，可搜索、切换或新增系统；没有系统时也可从空状态直接新增。当前系统旁的“更多”包含“系统信息”和“导出资料”，星标用于收藏该系统。

横向分类切换访问入口、服务器、数据库／中间件、账号、应用部署、运行维护和文档。未打开记录时显示完整表格，便于比较；打开记录后，宽窗口显示摘要列表与详情。搜索、环境、标签筛选位于列表侧，运行维护还可按类型和状态筛选。搜索可以保留当前详情；改变分类、环境、标签或运维范围会在保存后关闭旧详情。

空间不足时详情单栏显示，点击“返回清单”恢复原分类、搜索、筛选和清单位置。详情中的“编辑”可补充资料；切换对象、返回、复制或打开系统操作前会等待保存，失败时保留输入并提示重试。

地址、用户名和秘密的复制入口保留在对象附近；启用主密码时，秘密按需解锁。完整账号清单仍可显示或隐藏秘密。勾选记录后显示选择数量、复制及相关选项，可取消选择；摘要和完整清单切换保留勾选，改变筛选范围会清理旧选择。

当前分类右侧提供新增和“批量录入”。台账的“文档”分类、对象相关文档及运维的“阅读步骤文档”均进入现有文档工作区；从对象新建文档会携带该对象背景。

“批量录入”支持访问入口、服务器、数据库、Redis、其他资源、服务、运行作业、备份策略、账号和部署节点。每批固定一个系统和一种类型，可以直接增加行、逐格填写，也可以从 Word／Excel 粘贴表格，映射字段后追加到已有行，再修改地址、说明、账号等内容。空白行不提交，错误行可修正、删除或取消勾选；每次最多新增 200 条。入口和资源每行可顺带一组账号，密码遮蔽显示并加密保存。

同批统一选择一个环境或“系统通用”，更多适用环境和标签保存后在详情补充。独立录入账号时整批选择同一所属对象，账号随所属对象展示；部署节点整批选择同一服务和明确环境。开始填写后不能直接切换类型，需先清空条目及粘贴内容，以免带入不适用的字段。

勾选的行校验通过后统一新增，疑似重复需要明确确认，已有同名限制仍然有效，不自动覆盖旧资料。提交失败保留输入供修正和重试，成功后显示创建与跳过数量。未提交内容只在本次窗口中保留，关闭窗口或退出应用前会提醒；需先提交或明确放弃，再重试退出或更新操作。

## 台账中的访问入口与服务器

在台账中选择系统后，可切换“访问入口”或“服务器”，环境通过清单筛选选择，也可在“更多 → 系统信息 → 环境管理”维护。访问入口和服务器都可以先作为系统通用记录，不必先建环境；筛选某个环境时会同时显示通用记录。

访问入口用于 Jenkins、GitLab 等工具。新增时名称必填，具名地址、首个账号角色、用户名和密码可以同屏填写，也可以留空；更多地址、Token、私钥和说明可按需展开。详情支持多个具名地址和多组角色账号；用星标选择常用地址、下拉框选择常用账号，再把入口设为常用，即可从工作台直接打开网站或复制账号。启用主密码后，秘密按需解锁；未启用时由系统账户加密保护。所有地址共用该入口下的账号。

服务器新增时可以一起填写名称、IP／主机名、端口、用途、首个账号的用户名和密码，只有名称必填。端口可留空，填写时须为 1 到 65535；密码遮蔽显示并加密保存。展开“操作系统与硬件配置”可补充操作系统、CPU、内存和硬盘；CPU 可直接写型号与核数，内存、硬盘可写“32G”“500G”。详情支持后续编辑和增加多组账号，没有登录权限时只记机器资料即可。登录协议、位置、资产编号和说明也可选填。

入口和服务器可复制到另一个系统，副本独立维护。默认复制普通资料和账号元数据，勾选复制秘密后按当前保护方式授权访问。服务器已有任务、文档或草稿引用时，先处理引用或复制为新记录，再调整环境，已有工作不会被自动改写。

新增台账、服务器配置、地址顺序、常用选择、收藏和秘密都包含在完整备份中。旧版台账及备份会在升级时保留原记录和关联。

## 数据库、中间件与应用部署

数据库／中间件新增时可选类型，填写产品、版本、连接及首个账号。配置资料按产品显示实例／服务名、库名、字符集、主备、DB 编号、命名空间／虚拟主机、持久化及目录等字段；不认识的产品可直接手填，并保留普通附加字段。名称和必要归属以外均可留空。密码、Token、私钥使用专门的凭据字段，不能通过普通附加字段冒充加密保存。

一份资源可维护多组具名连接，各自填写地址、端口、用途或节点角色，按需关联本系统服务器。第一组默认为常用，可改选或排序；独立地址留空时显示服务器地址并注明来源，不继承服务器登录端口。解除服务器关联会保留当前地址。跨系统复制保留连接的当前地址、解除原服务器关联，副本独立维护。批量录入每行填写首组连接及一组账号，更多连接和账号在详情补充。

“新增应用部署”可填写应用名称、用途／说明和代码仓库，也可勾选“同时记录部署”。不勾选时只创建应用；记录节点时需填写节点名称与环境，服务器、地址、端口及其他信息仍可后补。固定／按需是运行安排，普通进程、Docker、Kubernetes 等是部署方式，分别记录；版本、程序／镜像、部署目录、配置和日志位置、启停命令、健康检查地址可按需填写，不同环境和节点的资料互不覆盖。

应用和节点可引用多份本系统或通用操作文档，同一正文只维护一份，从对应详情直接打开。移除引用不删除正文；文档仍被引用时，删除或改变归属若会破坏引用，需要先解除或调整关联。部署与运维中的命令、路径、频率和验证结果都只是资料记录，工作台不会执行命令或自动监控外部系统。

## 账号、运行维护与环境说明

独立账号新增时可以填写用途或角色、用户名、密码，并展开 Token、私钥和说明；所属资源、入口或环境仍须明确。系统新增可选填登录地址与说明，环境新增和编辑均可填写说明。

运行维护新增时可选择作业或备份策略，并填写频率、状态、环境、关联应用／资源和步骤文档。作业可补脚本／命令、执行用户和日志位置；备份策略可补备份方式、目标位置、保留周期、恢复说明、最近恢复验证时间及结果。切换类型不自动删除已填资料。步骤文档继续使用本系统文档；复杂过程在文档中维护。

## 文档与任务归属

文档页的“归属”可筛选全部、通用文档或某个系统。新建文档继承当前范围，详情中可随时修改系统；清除系统关联即为通用文档。项目独立选择，系统改变后，已有文档和任务的项目不会被自动改写。

工作任务只可选关联系统，也可以先只记标题。旧项目、环境和资源背景保留为历史说明。

任务默认按创建年月分组，可切换为按预计完成时间查看。预计完成时间可留空、只选日期或补充时分；只选日期时，当天结束后才算逾期。未完成的逾期任务在最上方，临期任务紧随其后，其余任务继续按日期分组。同一任务只出现一次，完成后退出优先区，重开时重新判断。

默认提前 24 小时进入临期；详情中可指定临期开始日期及时分，仅日期从当天 00:00 开始。清除自定义设置会恢复默认规则，清除预计完成时间会一并清除临期设置。日期按本机日历解释，具体时分在跨时区后保持同一实际时刻。若因此出现临期起点晚于到期时间，恢复会保留原计划并在详情提示修正，不会阻止整份备份恢复或无关正文编辑。

“管理标签”提供全部任务共用的名称和颜色标签，一个任务可选多个。筛选默认匹配任一选中标签，可切换为全部匹配，并与系统、完成状态和搜索共同生效。删除标签只移除标记，不删除任务。标签颜色不改变临期排序。首页及台账的“相关工作”使用相同紧迫规则；工作回顾继续按实际开始、完成时间展示。

## 导出系统资料

在台账中选择系统，点击“更多 → 导出资料”打开“导出系统资料”弹窗。完整台账始终导出，文档和任务可分别勾选，默认均包含。任务默认导出全部；填写日期范围后，按本机时区下的任务开始日期筛选，包含起止日期当天，任一端留空表示该端不限。任务正文合并到系统总览，每份关联文档独立成文件。

可选择 Markdown、Word（DOCX）和 PDF。没有关联文档或取消勾选文档时，格式为单选，直接保存指定格式的一个文件，图片嵌入文件；切换到单文件时默认保留最后选中的格式。只有实际包含文档时才保存为 ZIP 包，此时可选择多种格式。单文件 Markdown 的图片使用内嵌数据，查看器需支持此类图片；Word 和 PDF 可直接查看内嵌图片。总览包含系统基本信息、项目历史、环境、服务部署、服务器配置、访问地址和账号。勾选包含文档时，也包含该系统应用或节点直接引用的通用文档；同一正文只导出一次，并保留对应跳转。未引用的通用文档、其他系统资料及回收站不包含在内。

默认包含账号密码，导出前按需解锁；Token 和私钥须另行勾选。所选秘密会以明文写入文件，交接前应确认接收对象和保存位置。取消解锁或保存不会生成文件，导出失败会清理本次临时输出。

系统资料包用于直接阅读和交接，不提供导入；换机恢复使用下方的完整加密备份。

外部图片会导出为说明文字，需显示图片时先在应用中导入。若源码包含原始 HTML，Markdown 导出会提示先将它放入代码块或选择 Word／PDF，避免正文结构被静默改变。

## 凭据保护与可选主密码

新资料库默认使用操作系统加密保护，保存、查看和复制密码、Token、私钥无需设置应用主密码。系统名称、地址、账号名、任务、文档和图片属于普通资料；写进备注或正文的敏感内容不会自动转为加密秘密，应放进账号的秘密字段。

启动、浏览普通资料和锁定时不会主动访问系统钥匙串。macOS 在首次使用系统保护的凭据或转换保护方式时仍可能要求钥匙串授权，更新或切换调试构建后也可能再次要求授权；这是系统对凭据访问的保护。已启用主密码后，日常解锁使用应用主密码。

已解锁且未过期的系统凭据会话会复用现有密钥，重复解锁请求不会再次读取钥匙串；主动锁定、闲置超时、系统锁屏和资料切换后仍须重新解锁。当前 macOS 安装包使用 ad-hoc 签名，跨版本仍可能重新请求授权，详见[发布说明](releases.md)。启用应用主密码后，日常凭据解锁不再依赖系统钥匙串；已有系统保护资料在切换时仍需先读取一次原密钥。

可在“设置 → 秘密保护”启用主密码，至少 6 个字符。启用后重启、闲置 15 分钟、系统锁屏、休眠、退出或主动锁定会撤销会话，下次查看或复制凭据时按需解锁。连续使用时不必重复输入。两种保护方式下，复制秘密后 30 秒都会清理仍由应用持有的剪贴板内容，后来复制的其他内容会保留。

“更改主密码”和“关闭主密码”都需要验证当前密码。关闭后凭据改由系统账户加密保管，可随时重新开启。保护转换成功前不会替换原资料；系统加密不可用时会提示失败，不会改为明文保存。主密码开关或更改不会改变独立备份密码。

系统保护依赖当前系统账户和可访问的系统保护材料，复制整个应用目录不等于可迁移备份。主密码丢失或系统保护材料不可用时，可凭完整备份及其备份密码恢复。

## 完整备份与换机

首次导出完整备份、启用自动备份或安装更新时，设置一次独立备份密码。日常使用及后续自动备份无需重复输入，启动应用不会要求先配置。取消配置会取消本次动作。

未启用应用主密码时，仅打开或取消备份密码设置不会请求钥匙串授权；确认“保存并继续”后才按需访问系统保护材料。系统授权失败时保留输入，可重试或取消。已配置的自动备份不会为了执行备份而解锁本机凭据。

“设置 → 导出完整备份”生成 `.cwb` 文件，包含项目历史、台账、账号、任务计划和标签、文档、必要偏好、草稿、回收站记录及引用图片。秘密锁定时仍可备份。备份整体加密：新格式凭文件和生成时的独立备份密码恢复；历史旧格式凭该文件生成时的旧密码恢复。新格式不需要源设备的 Keychain、DPAPI 或源主密码。

未配置备份密码时自动备份显示未启用。配置后沿用自动备份开关，在应用运行且有变更时每日成功备份一次，保留本设备同一序列最近 7 份有效自动备份。手动导出、恢复前副本和其他文件不会纳入清理。设置中可更改目录、查看成功时间或失败原因，并点击“立即备份”重试。应用退出后不运行备份服务。

已有主密码用户升级时，初始备份密码沿用升级前的主密码，此后分别管理。“更改备份密码”只影响之后生成的文件，旧备份仍用各自生成时的密码。本机凭据仍可访问时可重新设置今后的备份密码，但不能据此解开忘记密码的历史备份。

换机恢复步骤：

1. 将完整 `.cwb` 文件复制到目标电脑，打开“设置 → 从备份恢复”。
2. 输入这份文件的备份密码；旧格式使用生成时的主密码。预检会验证认证信息、资料结构、附件和凭据密文。
3. 查看摘要并确认整份替换。取消或密码错误不会修改当前资料。
4. 恢复后保留目标电脑选择的凭据保护方式。全新设备默认系统保护；已有主密码的目标电脑继续使用目标电脑自己的主密码。

恢复替换当前资料、草稿和回收站前，先保存一份当前资料的加密副本。已配置备份保护时，副本使用当前备份密码；尚未配置时，使用本次导入文件的备份密码，并在确认界面说明。副本保存在 `data/recovery/`，可通过同一入口恢复。副本写入或资料切换失败时保留原资料，可修复后重试。

恢复保留目标电脑的备份目录，清除原自动备份成功状态；工作资料、可访问性偏好和今后的备份保护来自导入包。历史备份仍按原密码管理。

## 统一外观

导航和工具栏采用 macOS 27 风格的半透明材质，资料区保持清晰的实色背景。设置中可选浅色、深色或跟随系统，也可减少透明度、增强对比或减少动态效果。Windows 使用系统窗口操作和字体，内容区共享相同控件和间距规范。

## 保存或恢复失败

保存失败时页面会保留编辑内容并显示错误，离开或退出会被阻止，直到保存成功。先按提示检查磁盘空间和目录权限，再重试；不要通过强制结束应用来代替保存。

备份目录不可用时，原有副本保持不变。更改目录或修复访问权限后重试，失败不会计为当天已经成功备份。

预检失败不替换资料。恢复前副本无法完成时，也不会切换资料库。遇到数据异常时先保留整个本机资料目录和已有备份，再根据错误信息处理，避免手动混合两份数据库与附件。
