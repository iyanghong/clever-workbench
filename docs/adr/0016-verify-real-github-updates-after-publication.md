# 目标版本的真实 GitHub 升级验收分两阶段执行

状态：已接受（维护者于 2026-10-29 确认）。

现有客户端只读取固定仓库的正式 `latest` Release，不能在目标版本仍为 Draft 时无替身地下载该版本。因此下一版在公开前先以固定源码和安装包完成断流恢复、校验、安装与隔离资料回归；公开后立即从已发布旧安装版经真实私有 GitHub 资产执行升级，并分别记录网络下载、资料备份、应用替换、新版健康确认或 macOS 人工处理。发布前的本地或模拟传输结果不写成目标版本的真实网络验收。

若发布后发现可复现的资料损坏或安装风险，先暂停该版作为自动更新目标并公告，再使用新版本号修复；普通可恢复网络中断记录为已知问题并提供手动安装路径。已发布标签与资产不重写。这一顺序接受“真实目标资产验收发生在公开之后”的时间窗口，避免为验收引入另一个仓库、非正式来源或绕过客户端固定来源检查。
