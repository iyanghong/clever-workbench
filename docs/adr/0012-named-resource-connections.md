# 数据库与中间件使用多组具名连接

同一套数据库或中间件可能同时有业务地址、管理地址及主备节点地址，单个地址字段无法清楚表达，拆成多份资源又会重复维护公共资料和账号。因此允许一份资源维护多组具名连接，各自可记录地址、端口、用途或节点角色，并可选关联已有服务器；连接本身不成为另一份资源，也不因地址相同自动合并对象。账号归属与同系统内对象复用仍遵守 [ADR 0008](0008-reuse-ledger-objects-within-system.md)。

2026-10-22：用户在台账字段完善访谈 Q2 选择此方案。该决策已确认，功能已接入当前代码；细节与后续确认见[需求规格](../../.scratch/ledger-field-completeness/spec.md)。

同日 Q9 确认首组连接默认为常用且可改选；连接没有独立地址时显示所关联服务器的地址并注明来源，手填地址优先。数据库账号仍属于数据库资源，服务器登录账号仍属于服务器，不因关联机器而混用。
