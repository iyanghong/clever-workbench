# 访问入口与服务器可直接归属系统

Jenkins、GitLab 和部分服务器不对应单一环境，强制环境归属会让用户为记录地址或机器先创建无实际意义的环境。访问入口和服务器因此直接属于单个系统，环境可选；现有服务器仍是同一份资源记录，不与新清单重复建模。用户选择跨系统复制为独立记录，不维护共享关系；这样可以先快速录入资料，再按需补充环境，并让每个系统独立维护自己的台账。

2026-10-19 补充：同一系统内的多范围复用按 [ADR 0008](0008-reuse-ledger-objects-within-system.md) 扩展，一份对象可在多个适用环境中展示；跨系统仍是独立副本。
