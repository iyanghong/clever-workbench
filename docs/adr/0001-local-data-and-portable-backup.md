# 单人本地资料库与备份迁移

工作台供用户个人使用，数据保存在当前设备并支持离线操作；macOS 与 Windows 之间通过备份迁移资料。用户在首轮需求访谈中选择了这一方式，首版无需自动同步或多人协作。完整备份包含资料与附件，并整体加密；换机时使用备份生成时的主密码恢复，解密不能依赖原设备的 Keychain 或 DPAPI。该策略在第三轮确认，使凭据保护与跨平台迁移同时成立。

2026-10-20：新备份使用主密码恢复的规则由 [ADR 0011](0011-independent-password-for-portable-backups.md) 替代，改用独立备份密码；完整备份含凭据、手动与自动备份均可跨设备恢复的要求继续有效。历史备份仍使用生成时的密码，本次调整尚未实施。
