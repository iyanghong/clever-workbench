# 完整备份使用独立恢复密码

主密码成为可选项后，本机系统加密不能单独满足跨设备恢复，因此手动与自动完整备份使用独立备份密码，配置一次后自动备份无需反复输入；备份仍包含全部资料与凭据，并可跨 macOS 和 Windows 恢复。该选择保留了电脑损坏或丢失后的恢复能力，代价是用户需要保留备份生成时的恢复密码，历史备份仍使用各自原有的密码。

2026-10-20：用户在本轮 Q10、Q11 确认该选择。本决策替代 ADR 0001、ADR 0004 中新备份必须使用应用主密码恢复的规则，主密码的开启、关闭和更改不应连带改变独立备份密码。Q14、Q15 进一步确认：新用户在首次备份或安装更新时配置备份密码，取消配置则取消本次动作，日常使用不受阻；已有用户初始沿用升级时主密码作为独立备份密码，此后分别管理。每份历史备份仍使用其生成时密码。
