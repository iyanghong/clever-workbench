# 本地模型导入经人工确认，原文与草稿不留存

外部交接资料包含内部敏感信息，因此模型只在本机处理文档并生成供人工核对的台账候选；用户确认后，通过台账与凭据的受控接口保存。模型负责建议，用户逐行确认写入的操作、环境和字段。工作台不持久化导入原文件、原文和未确认的分析草稿，只保存确认后的台账，以放弃软件内长期原文追溯和崩溃后草稿恢复为代价，减少敏感资料的持久副本。

软件和模型允许联网下载，文档内容不能因此发送远端，分析失败不能自动转用云模型。首版只导入明确的密码字段，Token、私钥暂缓；本地仍按既有边界专门保护凭据，普通台账不整体加密。

2026-11-17 确认本机处理、人工复核和资料留存边界。导入操作见[使用说明](../usage.md#用本地模型分析文件并导入台账)。

2026-11-19：用户将首版只新增的规则扩展为逐行新增、跳过或更新。未匹配环境的新增默认系统通用，更新保留原环境。模型比较同批及同系统已有对象，用户确认身份、目标、普通字段差异与环境后，以原有 ID 更新。未选字段、关联及已有凭据保留，原子保存和资料代次约束继续生效。
