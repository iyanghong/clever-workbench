# 应用与部署节点通过引用复用文档

多个应用或部署节点可能共用一份操作手册，将手册复制到每个对象下会使正文逐渐不一致。因此应用与部署节点通过可移除的引用关联多份本系统文档或通用文档，同一文档可被多处引用，正文仍只维护一份；原有系统、环境和资源归属不因引用改变，移除引用也不删除文档。
