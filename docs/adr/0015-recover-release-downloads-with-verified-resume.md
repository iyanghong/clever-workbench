# 更新包下载采用有界重试与受控续传

状态：已接受（维护者于 2026-10-29 确认）。

固定私有 GitHub Release 的 ZIP 曾在流式读取中途出现 HTTP/2 协议错误；同一资产随后能够完整下载。一次可恢复的网络错误不应迫使用户从头开始，也不能放宽来源、授权或安装包校验。因此 macOS 更新下载最多尝试三次，按无进度时间判断连接停滞；只有同一固定资产的部分响应范围可核对时才续传，否则从头获取，最终始终校验完整 SHA-256 和原生应用包。未完成片段仅在受控目录保留同一版本最多 24 小时，成功安装、取消、版本变化或校验失败时清理；授权只发送到固定 GitHub API，重定向后的 CDN 不携带凭据。

不把全局禁用 HTTP/2 当作默认修复：隔离对照中 HTTP/2 与 HTTP/1.1 均成功下载相同资产片段，错误码本身无法确定代理、CDN 或 Chromium 哪一侧引起中断。此决策增加临时片段归属、部分响应与超时状态的维护成本，换取慢速和偶发中断网络下可恢复的下载；不改变下载就绪后由用户选择何时安装的流程。
