# 操作指引随应用分发并在发布时绑定版本

操作指引由维护者在仓库中配置并随安装包分发，以支持离线查阅及内容与功能版本对应；待发布操作说明在发布时关联实际版本号和源码，GitHub 用户摘要与应用内完整指引从同一内容源生成。首版采用这一方式，远程独立更新指引需要另行决定获取来源、缓存及版本兼容边界。

2026-10-21：用户在 Q1、Q8、Q9 确认上述方向；Q7 明确选择指引校验仅提示、不阻止发布，因此内容编写义务与发布阻断规则分开处理。Q10–Q14 确认设备独立的提示记录、跨版本汇总及运行期降级，Q15–Q19 确认首批全部功能覆盖、JSON 内容模板、保留版本历史、非阻断警告与人工核对记录及 macOS 安装版主要验收边界。Q20 已确认[完整规范](../operation-guidance.md)作为后续实现依据；决定来源见[设计访谈](../../.scratch/operation-guidance/interview.md)，尚未实施。

2026-10-28：与已发布的资源连接和文档引用决策整合时，本决策从原本独立分支的 ADR 0012 调整为 ADR 0014；决定内容未改变。
