# 秘密字段加密并按需解锁

用户需要在应用内保存、查看和复制密码、Token、私钥，同时希望日常查询账号、地址和文档不被解锁打断。因此本机资料库只加密秘密字段，普通台账信息、任务、文档与图片保持可访问；重启后首次访问秘密时使用主密码解锁，闲置 15 分钟或系统锁屏后重新锁定。完整备份另行整体加密，使用备份生成时的主密码恢复；忘记密码且没有可解锁副本时，不能承诺找回秘密。本机文档正文和图片不会自动识别或加密其中的敏感内容。

2026-10-20：所有本机凭据都必须先设置主密码的要求由 [ADR 0010](0010-optional-master-password-for-local-secrets.md) 替代；主密码成为可选保护，未设置时采用系统加密保护。新备份改用独立恢复密码，见 [ADR 0011](0011-independent-password-for-portable-backups.md)；历史备份仍使用原密码。本次调整尚未实施。
