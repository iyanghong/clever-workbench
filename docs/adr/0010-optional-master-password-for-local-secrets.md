# 本机凭据支持可选主密码

用户希望不设置应用主密码也能保存、查看和复制凭据，因此本机凭据增加由操作系统加密能力保护的使用方式，主密码成为可选保护，凭据仍不以明文保存。该方式让日常使用随系统会话可用，同时意味着系统保护材料不可访问时，不能仅凭复制应用数据目录恢复凭据；可迁移备份使用独立恢复密码，见 [ADR 0011](0011-independent-password-for-portable-backups.md)。

2026-10-20：用户在本轮 Q3 确认该选择，并在 Q9 确认已有用户可关闭或重新开启主密码；关闭时先验证现有主密码并转换凭据保护方式，旧备份仍使用生成时的恢复凭证。本决策替代 ADR 0004 中“所有凭据访问都必须先设置主密码”的要求；已设置主密码的解锁规则继续有效。ADR 0001 的备份可跨设备、跨平台恢复要求继续有效，本决策不将完整备份改为只能在原设备解密。

用户在 Q17 确认完整方案并先保留文档，随后于 2026-10-20 调用 implement 授权实施。本决策已接入当前代码，验证范围见[实施记录](../../.scratch/task-time-and-appearance/implementation.md)。
